<h3 id="통신-과정">통신 과정</h3>
<h4 id="51--overall-communication-process-figure-2-below">5.1)  Overall Communication Process (Figure 2, below)</h4>
<ol>
<li><p>MCU가 시작 신호를 보내고, DHT11은 낮은 전력소비(?) 모드로부터 <code>running-mode</code>로 변하고, MCU가 시작 신호를 다 보낼때까지 기다린다.</p>
</li>
<li><p><code>1</code> 과정이 끝나면 DHT11 모듈은 습도와 온도 정보에 관련하여 MCU에 <code>40-bit</code>의 응답 신호를 보낸다.</p>
</li>
<li><p>MCU가 <code>start signal</code> 을 보내는 동안은 DHT11 소자는 MCU에 응답을 보내지 않는다. 
(생각해보면 1-Wire 통신이므로 당연한 말)</p>
</li>
<li><p>하나의 데이터(?)가 수집된 후, DHT11은 MCU가 다시 start signal을 보낼따까지 낮은 전력 소비 모드로 바뀐다.
<img alt="Figure 2 Overall Communication Process" src="https://velog.velcdn.com/images/mommers/post/25826547-36e2-4db4-872a-f272f86f4275/image.png" /></p>
</li>
</ol>
<h4 id="52-mcu-sends-out-start-signal-to-dht-figure-3-below">5.2 MCU Sends out Start Signal to DHT (Figure 3, below)</h4>
<ol>
<li>Data Singal-bus free status(?) 는 <code>high</code> voltage level로 설정된다.</li>
<li>MCU와 DHT11의 통신이 시작될 때, 
MCU의 programme(?)는 Data Single-bus voltage level을 <code>high</code> 에서 <code>low</code> 로 바꾸며 이 프로세스는 적어도 <code>18ms</code> 안에 DHT가 MCU의 신호를 탐지해야 한다.</li>
<li>이후, MCU는 <code>pull up voltage</code> &amp; <code>20~40us</code> 동안 DHT의 응답을 기다린다.
<img alt="Figure 3 MCU Sends out Start Signal &amp; DHT Responses" src="https://velog.velcdn.com/images/mommers/post/395a2528-992c-4950-a172-f390fb153e10/image.png" /></li>
</ol>
<h4 id="53-dht-responses-to-mcu-figure-3-above">5.3 DHT Responses to MCU (Figure 3, above)</h4>
<ol>
<li>DHT가 시작 신호를 탐지하면, 그 신호는 적어도 80us동안 <code>low-voltage-level</code> responce signal로 지속된다.</li>
<li>DATA Single-Bus는 <code>low</code> 전압 레벨이며, DHT가 응답 신호를 보내고 있다는 의미이다.</li>
<li>DHT가 응답 신호를 보낼 때, <code>voltage</code>는 풀업( <code>high</code> )되며, <code>80us</code> 동안 유지되며 데이터 전송을 준비한다.</li>
<li>DHT가 MCU로 데이터를 보낼 때, 데이터의 모든 비트가 <code>50us</code> 동안 low-voltage-level로 시작하고, high-voltage-level signal은 데이터 비트가 <code>0</code> 이냐 <code>1</code>이냐에 따라 달라진다.( 아래 Figures 4 and 5 참고 )</li>

<h3 id="습도-센서-실습-예제---틀린-부분-찾아서-고치기완">습도 센서 실습 예제 - 틀린 부분 찾아서 고치기(완)</h3>
<pre><code class="language-c">#include &lt;Arduino.h&gt;

uint8_t dht_data[5]; 
/*
dht_data : uint8_t 자료형인 이유
8bit integral RH data +
8bit decimal RH data +
8bit integral T data +
8bit decimal T data +
8bit check sum
*/

#define DHTPIN 2    // DHT11 통신

// 신호 대기 함수 (state: HIGH 또는 LOW될 때까지 대기/최대 타임아웃 반환)
int waitFor(uint8_t state, unsigned int timeout=100) {
    unsigned int count = 0;
    while (digitalRead(DHTPIN) != state) {  // 결국 다음 신호(signal)를 기다리는 동안 while 문이 동작하므로 !=
        delayMicroseconds(1);
        if (++count &gt; timeout) return 1; // timeout이니까 1 반환
    }
    return 0; // 왜 0 반환?
}

bool readDHT11_raw() {
    // 초기화
    for (int i = 0; i &lt; 5; i++) dht_data[i] = 0;

    // 1. MCU가 신호선 LOW로 18ms 이상
    pinMode(DHTPIN, OUTPUT);
    digitalWrite(DHTPIN, LOW);
    delay(20); 

    // 2. HIGH 20~40us
    digitalWrite(DHTPIN, HIGH);
    delayMicroseconds(35);

    // 3. 입력모드 전환(MCU -&gt; DHT11)

    // 이제 코드를 통해 입력을 넣어주는 것이 아닌
    // DHT11 소자가 출력하는 값을 읽어들여 코드를 동작
    pinMode(DHTPIN, INPUT_PULLUP);

    // 4. DHT11 응답대기 (최대 100us)
    if (waitFor(LOW)) return false;     // Low를 기다림. Low가 아닌 동안 us올라감
        // timeout이 되어 1이 반환되면, return false;
    if (waitFor(HIGH)) return false;    // HIGH를 기다림. HIGH가 아닌 동안 us올라감
        // timeout이 되어 1이 반환되면, return false;

    // 5. DHT11 신호대기 (데이터 전송 시작)
    if (waitFor(LOW)) return false;     // timeout이 되어 1이 반환되면, return false;

    //6. 실제 데이터 비트 수신 (40비트)
    /*
        dht_data : uint8_t 자료형인 이유
        8bit integral RH data +
        8bit decimal RH data +
        8bit integral T data +
        8bit decimal T data +
        8bit check sum
    */

    for (int j = 0; j &lt; 5; j++) { // dht_data [0]~[4] 반복
      for (int i = 7; i &gt;= 0; i--) { // dht_data는 자료형 uint8_t , 8비트 잡아주는 역할 
        while(digitalRead(DHTPIN) == LOW){
                if (waitFor(HIGH)) return false;    // timeout이 되어 1이 반환되면, return false;
        }; // 비트 시작 대기? 이게 왜 대기지?
        delayMicroseconds(40); // 40us 대기 후 상태 체크 , 40us였는데 50us로 바꿈(datasheet 따라)

        if (digitalRead(DHTPIN) == HIGH) {
          dht_data[j] |= (1 &lt;&lt; i); // 40us 후에도 HIGH면 '1'로 판단
          while(digitalRead(DHTPIN) == HIGH){ // 남은 HIGH 시간 대기
            if (waitFor(LOW)) return false;     // Low를 기다림. Low가 아닌 동안 us올라감
          }
        }
      }                
    }

    // 7. 체크섬 검증
    uint8_t sum = dht_data[0]+dht_data[1]+dht_data[2]+dht_data[3]; // [0]~[3] 더해서 [4] 인덱스와 비교
    if ((dht_data[4] != (sum &amp; 0xFF))) return false; 
    // [4] 인덱스 와 checksum &amp; 1111 1111 연산해서 같지 않다면? -&gt; 데이터 손실로 판단 -&gt; return false;

    return true; // 문제 없다면 bool 함수 반환값 true
}

void setup() {
    Serial.begin(9600);     // 9600 시리얼 통신
    pinMode(DHTPIN, INPUT_PULLUP);  // DHT11 (2번 핀), 기본 pull-up으로 설정
}

void loop() {
    if (readDHT11_raw()) {
        Serial.print(&quot;Humidity: &quot;);
        Serial.print(dht_data[0]);
        Serial.print(&quot;.&quot;);
        Serial.print(dht_data[1]);
        Serial.print(&quot;%  Temperature: &quot;);
        Serial.print(dht_data[2]);
        Serial.print(&quot;.&quot;);
        Serial.print(dht_data[3]);
        Serial.println(&quot;C&quot;);
    } else {
        Serial.println(&quot;DHT11 Data Error&quot;);
    }
    delay(2000);
}
