<h2 id="1-기본-구조-관련">1. 기본 구조 관련</h2>
<ul>
<li><code>setup()</code> : 전원이 켜지거나 리셋 되었을 때 한 번만 실행, 핀 모드 설정, 시리얼 초기화 등 초기 설정 담당</li>
</ul>
<pre><code class="language-c">void setup(){ 
}</code></pre>
<ul>
<li><code>loop()</code> : <code>setup()</code> 이후 무한 반복 실행, 실제 동작 로직 작성<pre><code class="language-c">void loop(){ 
}</code></pre>
</li>
</ul>
<hr />
<h2 id="2-핀-제어-함수">2. 핀 제어 함수</h2>
<ul>
<li><code>pinMode()</code> : 핀의 입출력 방향 설정<pre><code class="language-c">pinMode(pin, mode);</code></pre>
</li>
</ul>

<ul>
<li><code>digitalWrite()</code> : 디지털 핀에 HIGH(5V) / LOW(0V) 출력<pre><code class="language-c">digitalWrite(pin, value);
digitalWrite(7, HIGH); // LED ON
digitalWrite(7, LOW);  // LED OFF
</code></pre>
</li>
</ul>
<pre><code>| value | 의미 |
| ----- | -- |
| HIGH  | 5V |
| LOW   | 0V |

- `digitalRead()` : 디지털 입력 핀 상태 읽기, 반환 값 : `HIGH` 또는 `LOW`
```c
if(digitalRead(2) == HIGH){
  // 스위치 눌림
}</code></pre><hr />

<h2 id="4-시간-관련">4. 시간 관련</h2>
<ul>
<li><code>delay()</code> : ms 단위 대기, CPU 완전 정지(blocking)<pre><code class="language-c">delay(1000); // 1초 대기</code></pre>
</li>
<li><code>millis()</code> : 전원 켜진 후 흐른 시간(ms), delay 없이 타이머 구현 가능<pre><code class="language-c">unsigned long t = millis();</code></pre>
</li>
</ul>
<hr />
<h2 id="5-시리얼-통신">5. 시리얼 통신</h2>
<ul>
<li><code>Serial.begin()</code> : 시리얼 통신 시작, 보레이트 설정<pre><code class="language-c">Serial.begin(9600);</code></pre>
</li>
<li><code>Serial.print()</code> : 시리얼 모니터 출력, <code>println()</code> 줄바꿈 포함<pre><code class="language-c">Serial.print(&quot;Hello&quot;);
Serial.println(&quot;Hello&quot;);</code></pre>
</li>
<li><code>Serial.available()</code> : 수신 데이터 존재 여부 확인<pre><code class="language-c">Serial.available();</code></pre>
</li>
<li><code>Serial.read()</code> : 수신 데이터 1바이트 읽기<pre><code class="language-c">char c = Serial.read();</code></pre>
</li>
</ul>
