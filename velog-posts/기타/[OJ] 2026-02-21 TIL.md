<h3 id="문제-1-배열-만들기2">문제 1) 배열 만들기2</h3>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/7dcd48bc-0916-4f09-91b2-09d343d3b3c7/image.png" /></p>
<p>이건 도저히 모르겠다.. 어떤 조건을 해놔도 반례가 있었다. 그나마 생각한게 5로 나누기 연산자를 통해 나눴을 때 이뤄지는 수가 000001~111111 (각 자리수는 0또는1 ) 이라는 조건을 찾았는데, 이건 코드로 어떻게 옮길지 모르겠어서 다른 방법을 계속 찾아봤다.</p>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/1c55aeca-055c-41ba-ad1c-b8c5b0a9780f/image.png" /></p>
<p>사실 하드코딩하면 풀 수는 있겠다 생각했으나 조건이 도저히 생각이 안났다. 일단 풀고 싶어서 하드코딩쪽으로 생각했다.</p>
<p>정답값의 후보들을 미리 배열로 만들어놓고, l이상 r이하의 i가 정답값의 집합 안에 있는지 확인한다면 문제를 풀 수는 있겠는데, 좀 복잡한데 노가다인 느낌이 문제의 의도는 아닌 것 같았다. 그 후 생각난건 정답값의 후보들을 미리 배열로 만들어두고, 그 배열 내에서 l이상 r이하의 값들만 반환하면 될 것 같다고 생각이 들었다.</p>
<pre><code class="language-c">#include &lt;stdio.h&gt;
#include &lt;stdbool.h&gt;
#include &lt;stdlib.h&gt;

int* solution(int l, int r) {
    // return 값은 malloc 등 동적 할당을 사용해주세요. 할당 길이는 상황에 맞게 변경해주세요.
    int* answer = (int*)malloc(sizeof(int)*64);
    int solution[]={5,50,55,500,505,550,555,5000,5005,5050,5055,5500,5505,5550,5555, //15
                    50000,50005,50050,50055,50500,50505,50550,50555, // 8
                    55000,55005,55050,55055,55500,55505,55550,55555, // 8
                    500000,500005,500050,500055,500500,500505,500550,500555, // 8
                    505000,505005,505050,505055,505500,505505,505550,505555, // 8
                    550000,550005,550050,550055,550500,550505,550550,550555, // 8
                    555000,555005,555050,555055,555500,555505,555550,555555}; // 8 &gt; //48 + 15 = 63

    answer[0]=-1;
    int cnt=0;
    for(int i=0;i&lt;63;i++){
        if(l&lt;=solution[i]&amp;&amp;solution[i]&lt;=r) answer[cnt++]=solution[i];    
    }

    return answer;
}</code></pre>

<h3 id="문제--2-콜라츠-수열-만들기">문제  2) 콜라츠 수열 만들기</h3>
<p>마지막 값에 <code>answer[cnt++]=n;</code>을 해줬다가 계속 이상한 값이 나오는 오류가 생겼었다.
answer에 저장된 변수보다 크기가 1 컸기 때문에 쓰레기값이 저장된것으로 생각된다.</p>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/431a4bba-ef01-4a65-90db-610ff0a54e06/image.png" /></p>
<pre><code class="language-c">#include &lt;stdio.h&gt;
#include &lt;stdbool.h&gt;
#include &lt;stdlib.h&gt;

int* solution(int n) {
    // return 값은 malloc 등 동적 할당을 사용해주세요. 할당 길이는 상황에 맞게 변경해주세요.
    int* answer = (int*)malloc(sizeof(int)*n);
    int cnt=0;
    while(1){
        if(n==1) {
            answer[cnt]=n;   
            break;
        }
        if(n%2==0) {
            answer[cnt++]=n;
            n=n/2;
        }
        else if(n%2==1 &amp;&amp; n!=1) {
            answer[cnt++]=n;
            n=3*n+1;
        }
    }

    return answer;
}</code></pre>

<h3 id="문제-3-배열-만들기4">문제 3) 배열 만들기4</h3>
<p><strong>배열이 비었는지 확인하는 방법</strong>
내가 생각했던 건 아래 두개인데, 각각 배열이 비었는지 확인하는 방법으로 보긴 어려웠다.</p>
<ul>
<li><code>arr[0]='\0'</code> -&gt; char형 배열에서만 의미 있다.</li>
<li><code>arr=NULL</code> -&gt; 동적할당에 실패했는지 확인할 때 쓰인다.</li>
</ul>
<p><strong>동적 할당 후 배열이 비었는지 확인하는 법</strong></p>
<ol>
<li><p>Cnt로 관리 : cnt=0이면 배열이 비었다고 확인</p>
<pre><code class="language-c">int cnt=0;</code></pre>
</li>
<li><p>특정 값으로 초기화 : Memset을 통해 전부 -1로 초기화하고 -1이면 비었다고 확인</p>
<pre><code class="language-c">int* arr = (int*)malloc(sizeof(int)*10);
memset(arr, -1, sizeof(int)*10);</code></pre>
</li>
<li><p>Cnt로 관리 : 메모리 할당과 동시에 값을 0으로 초기화</p>
<pre><code class="language-c">int* arr = calloc(10, sizeof(int));</code></pre>
</li>
</ol>
<p><strong>동적 할당시 배열의 요소를 삭제하는 법</strong></p>
<p>마지막 조건에서, stk의 마지막 원소를 stk에서 제거합니다. 이 조건을 어떻게 처리해야할지 몰랐다. 조건문의 else 부분에 <code>stk[cnt]=0;</code> 이걸 계속 해주고 있었다.</p>
<p>동적 할당 시 배열 <code>[1,2,3]</code> 에서 마지막 원소를 제거하여 <code>[1,2]</code> 로 만들고 싶다면 배열의 인덱스 ex)cnt 를 한개 줄여주면 끝나는 문제였다. <code>cnt--;</code></p>
<hr />
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/fe62965b-7c5e-4690-ad29-503e31c7ae0c/image.png" /></p>
<pre><code class="language-c">#include &lt;stdio.h&gt;
#include &lt;stdbool.h&gt;
#include &lt;stdlib.h&gt;

// arr_len은 배열 arr의 길이입니다.
int* solution(int arr[], size_t arr_len) {
    // return 값은 malloc 등 동적 할당을 사용해주세요. 할당 길이는 상황에 맞게 변경해주세요.
    int* stk = (int*)malloc(sizeof(int)*arr_len);
    int cnt=0;
    for(int i=0;i&lt;arr_len;){
        if(i==0) {stk[cnt++]=arr[i++]; continue;}

        if(stk[cnt-1]&lt;arr[i]){
            stk[cnt++]=arr[i++];
        }
        else{
            cnt--;
        }
    }

    return stk;
}</code></pre>
