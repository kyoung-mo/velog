<h3 id="문제-2-조건-문자열다시">문제 2. 조건 문자열(다시)</h3>
<ul>
<li>의도와 다르게 우연히 정답이 된 문제였다. 나중에 다시 리뷰할 것</li>
</ul>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/8f2a2531-96ad-4fd2-8219-61af18ba16bd/image.png" /></p>
<ul>
<li><code>strcmp</code> 의 반환값<pre><code class="language-c">strcmp(&quot;&gt;&quot;, &quot;&gt;&quot;)  // 0 (같음)
strcmp(&quot;&gt;&quot;, &quot;&lt;&quot;)  // 0이 아닌 값 (다름)</code></pre>
<code>strcmp()</code> 는 두 문자열이 같으면 0을 반환,
두 문자열이 다르면 1을 반환하는 함수이다.</li>
</ul>
<hr />
<ul>
<li>작성했던 코드)</li>
</ul>
<pre><code class="language-c">#include &lt;stdio.h&gt;
#include &lt;stdbool.h&gt;
#include &lt;stdlib.h&gt;
#include &lt;string.h&gt;

// 파라미터로 주어지는 문자열은 const로 주어집니다. 변경하려면 문자열을 복사해서 사용하세요.
int solution(const char* ineq, const char* eq, int n, int m) {
    int answer = 0;


        if(strcmp(ineq,&quot;&gt;&quot;) &amp;&amp; strcmp(eq,&quot;=&quot;)){
            if(n&gt;=m) answer=0;
            else answer=1;
        }
        if(strcmp(ineq,&quot;&gt;&quot;) &amp;&amp; strcmp(eq,&quot;!&quot;)){
            if(n&gt;m) answer=0;
            else answer=1;
        }

        if(strcmp(ineq,&quot;&lt;&quot;) &amp;&amp; strcmp(eq,&quot;=&quot;)){
            if(n&lt;=m) answer=0;
            else answer=1;
        }
        if(strcmp(ineq,&quot;&lt;&quot;) &amp;&amp; strcmp(eq,&quot;!&quot;)){
            if(n&lt;m) answer=0;
            else answer=1;
        }


    return answer;
}</code></pre>
