<h3 id="문제-1-문자열-겹쳐쓰기">문제 1) 문자열 겹쳐쓰기</h3>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/e4a49021-9ff5-421e-bd5c-f05e6fefa109/image.png" /></p>
<p>함수를 작성하는 문제이고, 동적 할당 <code>malloc()</code> 이 들어간 문제의 초기 코드는 다음과 같이 주어진다.</p>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/99c26f39-85ed-4ff4-9859-cb78da3399cc/image.png" /></p>
<pre><code class="language-c">#include &lt;stdio.h&gt;
#include &lt;stdbool.h&gt;
#include &lt;stdlib.h&gt;

// 파라미터로 주어지는 문자열은 const로 주어집니다. 변경하려면 문자열을 복사해서 사용하세요.
char* solution(const char* my_string, const char* overwrite_string, int s) {
    // return 값은 malloc 등 동적 할당을 사용해주세요. 할당 길이는 상황에 맞게 변경해주세요.
    char* answer = (char*)malloc(sizeof(my_string));

    for (int i=0;i&lt;strlen(my_string);i++){
        answer=my_string; 
    }

    for(int i=0;i&lt;strlen(overwrite_string);i++){
        answer[i+s]=overwrite_string[i];
    }

    return answer;
}</code></pre>
<ul>
<li><p>malloc 함수를 통해 answer의 주소를 힙 영역을 가리키게 해놨는데, <code>answer=my_string;</code> 이라는 코드는 answer가 my_string의 시작 주소를 가리키게 하기 때문에 malloc이 의미가 없어지고, 굳이 for문을 쓰지 않아도 된다.</p>
</li>
<li><p>malloc 함수를 쓰고 싶다면  <code>char* answer = (char*)malloc(sizeof(my_string)+1)</code> 을 통해 <code>\0</code> (널 문자)를 마지막에 포함 해주어야한다. 첫 번째 <code>for</code>문도 <code>i&lt;strlen(my_string)+1</code> 로 범위 수정.</p>
</li>
<li><p>참고로 첫 번째 for문은 <code>strcpy(answer, my_string);</code> 으로 대체 가능하다.</p>
</li>
</ul>

<h3 id="문제-2-문자열-섞기">문제 2) 문자열 섞기</h3>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/03a1ee3a-01b3-4274-858d-66f7daacbb2d/image.png" /></p>
<pre><code class="language-c">#include &lt;stdio.h&gt;
#include &lt;stdbool.h&gt;
#include &lt;stdlib.h&gt;
#include &lt;string.h&gt;

// 파라미터로 주어지는 문자열은 const로 주어집니다. 변경하려면 문자열을 복사해서 사용하세요.
char* solution(const char* str1, const char* str2) {
    // return 값은 malloc 등 동적 할당을 사용해주세요. 할당 길이는 상황에 맞게 변경해주세요.
    char* answer = (char*)malloc(strlen(str1)+strlen(str2)+1);

    for(int i=0;i&lt;(strlen(str1)+strlen(str2)+1);i++){
        if(i%2==0){
            answer[i]=str1[i/2];
        }
        else {
            answer[i]=str2[i/2];
        }
    }

    return answer;
}</code></pre>
<ul>
<li>strlen(str1)을 해준 경우, NULL 문자를 포함x</li>
<li>NULL 문자 이전까지 문자가 몇개인지를 반환한다.</li>
<li><code>strlen()</code> 의 반환형은 <code>size_t</code>로, 부호없는 정수형을 반환한다.</li>
</ul>
