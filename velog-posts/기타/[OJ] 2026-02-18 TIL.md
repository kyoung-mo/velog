<h3 id="문제-1-마지막-두-원소">문제 1) 마지막 두 원소</h3>
<ul>
<li><code>int</code> 형 배열에서는 마지막에 <code>NULL</code> 문자가 붙지 않는다.</li>
<li>NULL(<code>\0</code>) 문자는 <code>char</code> 형 배열에서만 마지막에 붙는다.</li>
<li><code>malloc()</code> 은 바이트 단위로 할당한다.</li>
</ul>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/7f9d2c29-d83e-405d-9c65-46e8c19f8dbd/image.png" /></p>
<pre><code class="language-c">#include &lt;stdio.h&gt;
#include &lt;stdbool.h&gt;
#include &lt;stdlib.h&gt;

// num_list_len은 배열 num_list의 길이입니다.
int* solution(int num_list[], size_t num_list_len) {
    // return 값은 malloc 등 동적 할당을 사용해주세요. 할당 길이는 상황에 맞게 변경해주세요.
    int* answer = (int*)malloc(sizeof(int)*(num_list_len+1));
    for(int i=0;i&lt;num_list_len;i++){
        answer[i]=num_list[i];
    }

    if(num_list[num_list_len-1]&gt;num_list[num_list_len-2]){
        answer[num_list_len]=num_list[num_list_len-1]-num_list[num_list_len-2];
    }
    else{
        answer[num_list_len]=num_list[num_list_len-1]*2;
    }

    return answer;
}</code></pre>

    // return 값은 malloc 등 동적 할당을 사용해주세요. 할당 길이는 상황에 맞게 변경해주세요.
    int* answer = (int*)malloc(sizeof(int)*queries_rows);
