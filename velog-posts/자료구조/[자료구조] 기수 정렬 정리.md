<h3 id="정의">정의</h3>
<p>기수(radix) :  수 체계에서 한 자리에 표현할 수 있는 서로 다른 숫자의 개수 <code>ex) 10진수에서 10</code></p>
<p>기수 정렬               :  각  자리수(digit)를 기준으로 데이터를 정렬하는 <strong>비교 연산이 <code>없는</code> 정렬 알고리즘</strong></p>
<h3 id="역사">역사</h3>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/a105adc8-3c42-40dd-a55d-bd802de2af5d/image.png" /></p>
<h3 id="1890년-허먼-홀러리스herman-hollerith"><strong>1890년 허먼 홀러리스(Herman Hollerith)</strong></h3>
<ul>
<li>미국 인구조사국에서 <strong>천공카드</strong>(punch card)를 이용해 인구 데이터를 처리할 때, <strong>자릿수별로 정렬하는 방식</strong>이 필요했다.</li>
<li>홀러리스는 <strong>기계식 데이터 처리기</strong>를 개발했고, 이를 위한 정렬 방식으로 자릿수 기반의 정렬이 사용되었다.</li>
</ul>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/aba985ee-3791-4ad7-aaa4-fcd813abad0b/image.png" /></p>
<h3 id="1954년-harold-h-seward"><strong>1954년 Harold H. Seward</strong></h3>
<ul>
<li>현대적인 의미의 기수정렬 알고리즘을 정립.</li>
<li>&quot;Radix Sort&quot;라는 용어와 알고리즘을 명확하게 정리한 논문을 발표.</li>
<li>당시 <strong>컴퓨터의 정렬 성능 향상</strong>이 주요 연구 과제였으며, <strong>대용량 숫자 데이터 정렬</strong>을 위해 비교 기반 방식이 주목받음.</li>
</ul>
<h3 id="종류">종류</h3>
<hr />
<p><strong>LSD(Least‑Significant Digit) 우선      :</strong>  첫 번째 자리수 부터 올라감</p>
<p><strong>MSD(Most‑Significant Digit) 우선</strong>    :  최상위 자리부터 내려감</p>
<hr />
<h3 id="장점">장점</h3>
<ol>
<li><p>시간 복잡도 선형적(1차함수, 직선, linear)이다 - 비교 연산 없이 정렬하여 대규모 데이터에서 퀵 정렬·병합 정렬보다 빠를 수 있음.</p>
<ul>
<li>시간 복잡도 <strong>`평균:</strong> <strong>O(d × (n + k)) ==  최악:O(d × (n + k)</strong>`</li>
<li>원소 수(n)가 많고 자리 수(d)가 작을수록 유리</li>
</ul>
</li>
<li><p>안정 정렬 - 동일한 키 값을 가진 데이터의 순서가 보존되며 각 자리수 별 정렬 시 큐(Queue) 자료구조를 사용하여 입력 순서 유지.</p>
<ul>
<li><p>큐(Queue) 자료구조:  먼저 들어온 데이터를 먼저 처리하는 선입선출 (First-in-First-out, <code>FIFO</code>) 구조</p>
<p>  <img alt="image.png" src="attachment:c955527d-9c8a-490c-8cea-f2ba0faf69fa:image.png" /></p>
</li>
</ul>
</li>
</ol>
<h3 id="단점">단점</h3>
<ol>
<li>메모리 사용량이 큼 - 버킷 개수가 고정되지 않아 최대 데이터 크기 × 기수만큼 메모리를 사용할 수 있음.</li>
<li>데이터 유형 제한 - 실수(부동 소수점)처럼 비교 연산을 할 수 없는 데이터에는 부적합하며, 문자열 길이가 불규칙한 경우 등도 전처리가 필요함.</li>
</ol>
<h3 id="상세-정렬-과정">상세 정렬 과정</h3>
<ol>
<li>정렬할 데이터의 최대 자릿수를 결정.</li>
<li>가장 낮은 자리수부터 시작하여 계수 정렬을 반복.</li>
<li>각 단계에서 해당 자리수를 기준으로 정렬된 배열을 생성.</li>
<li>모든 자리수를 처리하면 최종 정렬된 배열 완성.</li>
</ol>
