<h3 id="1-기수-정렬">1. 기수 정렬</h3>
<ul>
<li><p>기수(radix) :  수 체계에서 한 자리에 표현할 수 있는 서로 다른 숫자의 개수 <code>ex) 10진수에서 10</code></p>
</li>
<li><p>각  자리수(digit)를 기준으로 데이터를 정렬하는 비교 연산이 없는 정렬 알고리즘</p>
</li>
<li><p>LSD, MSD 방식이 있다.</p>
</li>
</ul>
<ol>
<li><p><strong>LSD(Least‑Significant Digit) 우선      :</strong>  첫 번째 자리수 부터 올라감</p>
</li>
<li><p><strong>MSD(Most‑Significant Digit) 우선</strong>    :  최상위 자리부터 내려감</p>
</li>
</ol>
<hr />
<ul>
<li><h3 id="장점">장점</h3>
</li>
</ul>
<ol>
<li><p>시간 복잡도 선형적(1차함수, 직선, linear)이다 - 비교 연산 없이 정렬하여 대규모 데이터에서 퀵 정렬·병합 정렬보다 빠를 수 있음.</p>
<ul>
<li>시간 복잡도 <strong>`평균:</strong> <strong>O(d × (n + k)) ==  최악:O(d × (n + k)</strong>`</li>
<li>원소 수(n)가 많고 자리 수(d)가 작을수록 유리</li>
</ul>
</li>
<li><p>안정 정렬 - 동일한 키 값을 가진 데이터의 순서가 보존되며 각 자리수 별 정렬 시 큐(Queue) 자료구조를 사용하여 입력 순서 유지.</p>
<ul>
<li>큐(Queue) 자료구조:  먼저 들어온 데이터를 먼저 처리하는 선입선출 (First-in-First-out, <code>FIFO</code>) 구조</li>
</ul>
</li>
</ol>
<hr />
<ul>
<li><h3 id="단점">단점</h3>
</li>
</ul>
<ol>
<li>메모리 사용량이 큼 - 버킷 개수가 고정되지 않아 최대 데이터 크기 × 기수만큼 메모리를 사용할 수 있음.</li>
<li>데이터 유형 제한 - 실수(부동 소수점)처럼 비교 연산을 할 수 없는 데이터에는 부적합하며, 문자열 길이가 불규칙한 경우 등도 전처리가 필요함.</li>
</ol>
<hr />
<h3 id="2-정렬-과정">2. 정렬 과정</h3>
<ol>
<li>정렬할 데이터의 최대 자릿수를 결정.</li>
<li>가장 낮은 자리수부터 시작하여 계수 정렬을 반복.</li>
<li>각 단계에서 해당 자리수를 기준으로 정렬된 배열을 생성.</li>
<li>모든 자리수를 처리하면 최종 정렬된 배열 완성.</li>
</ol>

<h3 id="3-시간-복잡도">3. 시간 복잡도</h3>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/dbe26a59-2b65-476a-88f4-230e815ad985/image.png" /></p>
<p>시간 복잡도: <code>O(d(n+k))</code></p>
<ul>
<li><code>n</code>: 정렬할 데이터의 개수</li>
<li><code>d</code>: 최대 자릿수</li>
<li><code>k</code>: 기수 (보통 10진수이므로 k=10)</li>
</ul>
<p>기수 정렬은 자릿수(d)만큼 반복하며, 각 반복마다 모든 데이터(n)를 버킷(k개)에 분배하고 수거하는 과정을 거친다. </p>

<h3 id="4-예제">4. 예제</h3>
<pre><code class="language-c">#define _CRT_SECURE_NO_WARNINGS
#include &lt;stdio.h&gt;
#include &lt;stdlib.h&gt;
#include &lt;time.h&gt;

#define MAX   1000000   // 난수 0~MAX
#define SIZE  1000000   // Queue size
#define DIGIT 10        // 기수

//int n = sizeof(arr) / sizeof(arr[0]);

//기수정렬을 진행할 버킷
int bucket[DIGIT][SIZE];

//배열을 queue처럼 사용하기 위해 각 자리수마다 count 저장
int bucket_count[DIGIT];

//배열 요소 출력 함수
void print_arr(int*);

//생성된 난수 중에서 최대 자리수 구하기
int get_max(int*);

//기수정렬을 진행
void radix_sort(int*);

//난수 배열 생성후 리턴
int* generateRandomArr(int size);

int main() {
    int* arr = generateRandomArr(MAX);
    int n = MAX;

    clock_t start, end;     // 시간 측정 변수 선언
    double duration;        // 경과 시간(초)

    start = clock();
    radix_sort(arr);
    end = clock();

    duration = (double)(end - start) / CLOCKS_PER_SEC;  // 초 단위로 변환

    printf(&quot;소요 시간: %f초\n&quot;, duration);

    //printf(&quot;정렬 후 배열:\n&quot;);
    printf(&quot;%d, %d\n\n&quot;, arr[SIZE - 2], arr[SIZE - 1]);
    print_arr(arr);
    free(arr);
    return 0;
}

// 가장 큰 수를 찾아 몇자릿수까지 정렬해야하는 지 판단
int get_max(int* arr) {
    int max = arr[0];
    for (int i = 1; i &lt; MAX; i++) {
        if (arr[i] &gt; max)
            max = arr[i];
    }
    return max;
}

// 기수 정렬 함수 LSD 방식
void radix_sort(int* arr) {
    int n = MAX;
    int i, j, k;
    int max = get_max(arr);

    // 1의 자리부터 10, 100 ... 자리까지 반복
    for (int exp = 1; max / exp &gt; 0; exp *= 10) {
        //printf(&quot;%d의 자리 정렬\n&quot;, exp);
        // 버킷 초기화 (queue초기화)
        for (i = 0; i &lt; DIGIT; i++)
            bucket_count[i] = 0;

        // 숫자들을 해당 자릿수에 따라 버킷에 넣기
        for (i = 0; i &lt; n; i++) {
            int digit = (arr[i] / exp) % 10;
            bucket[digit][bucket_count[digit]++] = arr[i];
        }

        // queue에서 값 꺼내 배열에 저장
        k = 0;
        for (i = 0; i &lt; DIGIT; i++) {
            for (j = 0; j &lt; bucket_count[i]; j++) {
                arr[k++] = bucket[i][j];
            }
        }
    }
}

// 출력 함수
void print_arr(int* arr) {
    for (int i = MAX - 100; i &lt; MAX; i++) {
        if (!(i % 10)) printf(&quot;\n&quot;);
        printf(&quot;%10d&quot;, arr[i]);
    }
}

int* generateRandomArr(int size) {
    printf(&quot;난수 생성중...\n&quot;);
    int* arr;
    srand(0); // 난수 시드 초기화
    // 동적 메모리로 정수 배열 할당
    arr = (int*)malloc(sizeof(int) * size);
    if (arr == NULL) {
        printf(&quot;메모리 할당 실패\n&quot;);
        return arr;
    }
    // 난수로 배열 초기화
    for (int i = 0; i &lt; size; i++) {
        arr[i] = (((rand() &lt;&lt; 15) | rand()) % (size + 1));
    }
    printf(&quot;난수 생성 완료\n&quot;);
    return arr;
}</code></pre>
