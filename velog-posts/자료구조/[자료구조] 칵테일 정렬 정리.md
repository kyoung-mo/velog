<h1 id="칵테일-정렬-cocktail-sort">칵테일 정렬 (Cocktail Sort)</h1>
<blockquote>
<p>버블 정렬의 한계를 개선한 양방향 정렬 알고리즘</p>
</blockquote>
<hr />
<h2 id="칵테일-정렬이란">칵테일 정렬이란?</h2>
<ul>
<li><strong>버블 정렬(Bubble Sort)을 개선한 알고리즘</strong></li>
<li>한 방향이 아닌 <strong>양방향으로 비교 및 교환 수행</strong></li>
<li><code>Shaker Sort</code>라고도 불림</li>
</ul>
<p><img alt="칵테일 정렬 동작" src="https://upload.wikimedia.org/wikipedia/commons/e/ef/Sorting_shaker_sort_anim.gif" /></p>
<hr />
<h2 id="핵심-아이디어">핵심 아이디어</h2>
<h3 id="버블-정렬의-문제점">버블 정렬의 문제점</h3>
<ul>
<li>항상 <strong>왼쪽 → 오른쪽</strong> 한 방향으로만 비교</li>
<li>작은 값이 뒤에 있어도 한 번에 이동하지 못함</li>
</ul>
<h3 id="칵테일-정렬의-개선점">칵테일 정렬의 개선점</h3>
<ul>
<li><strong>Forward + Backward</strong> 두 방향 탐색</li>
<li>한 사이클에서<ul>
<li>최댓값 → 맨 뒤</li>
<li>최솟값 → 맨 앞</li>
</ul>
</li>
</ul>
<p>➡️ 불필요한 비교 횟수 감소</p>
<hr />
<h2 id="한-사이클-동작">한 사이클 동작</h2>
<h3 id="1-forward-pass">1. Forward Pass</h3>
<ul>
<li>인접한 두 원소 비교(왼쪽 → 오른쪽)</li>
<li>큰 값을 오른쪽으로 이동</li>
<li><strong>최댓값 1개가 맨 뒤에 고정</strong></li>
</ul>
<h3 id="2-backward-pass">2. Backward Pass</h3>
<ul>
<li>역방향으로 비교(오른쪽 → 왼쪽)</li>
<li>작은 값을 왼쪽으로 이동</li>
<li><strong>최솟값 1개가 맨 앞에 고정</strong></li>
</ul>
<p>위 과정을 정렬된 구간을 제외하며 반복</p>
<hr />
<h2 id="예제-배열-동작-과정">예제 배열 동작 과정</h2>
<p>초기 배열
[5, 1, 4, 2, 8]</p>
<h3 id="▶-forward-pass">▶ Forward Pass</h3>
<p>[1, 4, 2, 5, 8]</p>
<ul>
<li><code>8</code>이 마지막 위치에 고정</li>
</ul>
<h3 id="▶-backward-pass">▶ Backward Pass</h3>
<p>[1, 2, 4, 5, 8]</p>
<ul>
<li><code>1</code>이 첫 번째 위치에 고정</li>
</ul>
<p>더 이상 교환이 발생하지 않으면 종료</p>

<h2 id="간단한-칵테일-정렬-c언어-구현">간단한 칵테일 정렬 c언어 구현</h2>
<pre><code class="language-c">## 버블정렬

void bubble_sort(int* arr, int size) {
    for (int i = 0; i &lt; size - 1; i++) {
        for (int j = 0; j &lt; size - i - 1; j++) {
            if (arr[j] &gt; arr[j + 1]) 
                swap(&amp;arr[j], arr[j + 1]);
        }
    }
}

void cocktail_sort(int* arr, int size) {
    int start = 0, end = size - 1;

    while (start &lt; end) {
        for (int i = start; i &lt; end; i++) {
            if (arr[i] &gt; arr[i + 1]) 
                swap(&amp;arr[i], &amp;arr[i + 1]);
        }
        end--;

        if (start &gt;= end) break;

        for (int i = end; i &gt; start; i--) {
            if (arr[i] &lt; arr[i - 1]) 
                swap(&amp;arr[i], &amp;arr[i - 1]);
        }
        start++;
    }

<h2 id="전체-코드">전체 코드</h2>
<pre><code class="language-c">#include &lt;stdio.h&gt;
#include &lt;stdlib.h&gt;
#include &lt;time.h&gt;

#define SIZE 10000

double compare_count = 0;
double swap_count = 0;

void swap(int* a, int* b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}

void cocktail_sort(int* arr, int size) {
    int start = 0, end = size - 1;
    int isEnd = 0;
    compare_count = 0;
    swap_count = 0;

    while (1) {
        isEnd = 1;
        for (int i = start; i &lt; end; i++) {
            compare_count++;
            if (arr[i] &gt; arr[i + 1]) {
                swap(&amp;arr[i], &amp;arr[i + 1]);
                swap_count++;
                isEnd = 0;
            }
        }
        end--;
        if (isEnd) break;

        isEnd = 1;
        for (int i = end; i &gt; start; i--) {
            compare_count++;
            if (arr[i] &lt; arr[i - 1]) {
                swap(&amp;arr[i], &amp;arr[i - 1]);
                swap_count++;
                isEnd = 0;
            }
        }
        start++;
        if (isEnd) break;
    }
}

void bubble_sort(int* arr, int size) {
    int is_end = 0;
    compare_count = 0;
    swap_count = 0;

    for (int i = 0; i &lt; size - 1; i++) {
        is_end = 1;
        for (int j = 0; j &lt; size - i - 1; j++) {
            compare_count++;
            if (arr[j] &gt; arr[j + 1]) {
                swap(&amp;arr[j], &amp;arr[j + 1]);
                swap_count++;
                is_end = 0;
            }
        }
        if (is_end) break;
    }
}

int main() {
    int* reversed; reversed = (int*)malloc(sizeof(int) * SIZE);
    int* random; random = (int*)malloc(sizeof(int) * SIZE);

    srand(0);

    clock_t start, end;
    double duration;


    for (int i = 0; i &lt; SIZE; i++)
        reversed[i] = SIZE - i;

    printf(&quot;\n[역순 배열(최악)]\n&quot;);

    start = clock();
    bubble_sort(reversed, SIZE);
    printf(&quot;버블 정렬 비교 횟수: %.0lf\n&quot;, compare_count);
    printf(&quot;버블 정렬 스왑 횟수: %.0lf\n&quot;, swap_count);
    end = clock();

    duration = (double)(end - start) / CLOCKS_PER_SEC;
    printf(&quot;소요 시간 : %.2f초\n&quot;, duration);

    for (int i = 0; i &lt; SIZE; i++)
        reversed[i] = SIZE - i;

    start = clock();
    cocktail_sort(reversed, SIZE);
    printf(&quot;칵테일 정렬 비교 횟수: %.0lf\n&quot;, compare_count);
    printf(&quot;칵테일 정렬 스왑 횟수: %.0lf\n&quot;, swap_count);
    end = clock();

    duration = (double)(end - start) / CLOCKS_PER_SEC;
    printf(&quot;소요 시간 : %.2f초\n&quot;, duration);





    for (int i = 0; i &lt; SIZE; i++)
        random[i] = ((rand() &lt;&lt; 15) | rand()) % (SIZE + 1);

    printf(&quot;\n[랜덤 배열(평균)]\n&quot;);
    start = clock();
    bubble_sort(random, SIZE);
    printf(&quot;버블 정렬 비교 횟수: %.0lf\n&quot;, compare_count);
    printf(&quot;버블 정렬 스왑 횟수: %.0lf\n&quot;, swap_count);
    end = clock();

    duration = (double)(end - start) / CLOCKS_PER_SEC;
    printf(&quot;소요 시간 : %.2f초\n&quot;, duration);


    for (int i = 0; i &lt; SIZE; i++)
        random[i] = ((rand() &lt;&lt; 15) | rand()) % (SIZE + 1);

    start = clock();
    cocktail_sort(random, SIZE);
    printf(&quot;칵테일 정렬 비교 횟수: %.0lf\n&quot;, compare_count);
    printf(&quot;칵테일 정렬 스왑 횟수: %.0lf\n&quot;, swap_count);
    end = clock();

    duration = (double)(end - start) / CLOCKS_PER_SEC;
    printf(&quot;소요 시간 : %.2f초\n&quot;, duration);



    free(reversed);
    free(random);
}</code></pre>
