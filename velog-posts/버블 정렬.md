<h3 id="🫧버블-정렬이란">🫧버블 정렬이란?</h3>
<p>서로 인접한 두 원소를 비교하여 정해진 기준(오름차순 또는 내림차순)에 따라 자리를 바꾸며 정렬하는 알고리즘으로, 물속의 거품이 수면 위로 올라오는 모습과 비슷하여 '버블 정렬'이라 이름이 붙었습니다.</p>
<h3 id="🔁-버블-정렬이-동작하는-방식은-오름차순-기준">🔁 버블 정렬이 동작하는 방식은? (오름차순 기준)</h3>
<ol>
<li>첫 번째 원소와 두 번째 원소를 <strong>비교</strong></li>
<li>첫 번째 원소가 더 크면 두 원소의 위치를 <strong>교환(swap)</strong></li>
<li>두 번째 원소와 세 번째 원소를 비교하는 식으로 마지막 원소까지 <strong>반복</strong></li>
<li>이렇게 한 바퀴 돌면 <strong>가장 큰 값이 맨 뒤에 고정</strong></li>
<li>마지막으로 이동한 원소를 제외하고 정렬될 때까지 처음부터 위 과정을 <strong>반복</strong></li>
</ol>

<h3 id="📄-버블-정렬-코드-예시">📄 버블 정렬 코드 예시</h3>
<ul>
<li><p>기본 버블 정렬</p>
<pre><code class="language-c">  #include &lt;stdio.h&gt;

  void bubbleSort(int arr[], int n) {
      int i, j, temp;

      // 전체 데이터를 순회 (회전)
      // 인접한 두 요소를 비교하며 큰 수를 뒤로 보냄
      // (n-1-i)인 이유는 각 회전이 끝날 때마다 맨 뒤의 숫자가 확정되기 때문
      for (i = 0; i &lt; n - 1; i++) {
              for (j = 0; j &lt; n - 1 **- i**; j++) {
              if (arr[j] &gt; arr[j + 1]) {
                  // 두 수의 자리를 바꿈 (Swap)
                  temp = arr[j];
                  arr[j] = arr[j + 1];
                  arr[j + 1] = temp;
              }
          }
      }
  }

  int main() {
      int data[] = {64, 34, 25, 12, 22, 11, 90};
      int n = sizeof(data) / sizeof(data[0]);

      printf(&quot;정렬 전 배열: \n&quot;);
      for (int i = 0; i &lt; n; i++) printf(&quot;%d &quot;, data[i]);
      printf(&quot;\n\n&quot;);

      bubbleSort(data, n);

      printf(&quot;정렬 후 배열: \n&quot;);
      for (int i = 0; i &lt; n; i++) printf(&quot;%d &quot;, data[i]);

      return 0;
  }</code></pre>

<h3 id="📌-버블-정렬-특징">📌 버블 정렬 특징</h3>
<ol>
<li>시간 복잡도 O(n²)  - 기본 버블 정렬</li>
</ol>
<aside>
💡

<p><strong>* 매 회전(pass)마다 인접한 원소를 끝까지 비교</strong></p>
<p>1회전: (n−1)번 비교</p>
<p>2회전: (n−2)번 비교</p>
<p>3회전: (n−3)번 비교</p>
<p>…</p>
<p>(n−1)회전: 1번 비교</p>
<p><strong>*총 비교 횟수 합</strong></p>
<p>(n−1)+(n−2)+...+1 = n (n-1) / 2 → 대략 n^2 /2  수준이라서 <strong>O(n²)</strong> 입니다.</p>
</aside>

<p>→ 데이터가 많아질수록 시간이 제곱으로 늘어남 (연산 횟수 계산)</p>
<ol>
<li>공간 복잡도 O(1) - 기본 버블 정렬</li>
</ol>
<aside>
💡

<p>원래 있던 배열 안에서 숫자 두 개의 위치만 바꾸는 방식(In-place sort)으로 입력 배열 외에 추가로 필요한 메모리는 교환을 위한 변수(<code>temp</code>) 하나 정도뿐이기 때문에 <strong>데이터가 아무리 많아져도 추가 메모리를 거의 쓰지 않습니다.</strong> → 실행되는 동안 메모리 공간이 일정</p>
</aside>

<li><p>50만개 정렬코드</p>
<pre><code class="language-c">  #include &lt;stdio.h&gt;
  #include &lt;stdlib.h&gt;
  #include &lt;time.h&gt;

  #define SIZE 500000  // 배열 크기 (테스트 목적상 작게 설정)

  void bubbleSort(int* arr, int size) {
      int temp;
      for (int i = 0; i &lt; size - 1; i++) {
          int swapped = 0;
          for (int j = 0; j &lt; size - i - 1; j++) {
              if (arr[j] &gt; arr[j + 1]) {
                  // Swap
                  temp = arr[j];
                  arr[j] = arr[j + 1];
                  arr[j + 1] = temp;
                  swapped = 1;
              }
          }
          if (!swapped) break;  // 이미 정렬되었으면 중단, 바꿀 값 없기 때문에 초기화된 swap이 그대로 유지되어 빠져나감
      }
  }

  void new_bubbleSort(int* arr1, int size) {
      int temp;
      int newSize = size;
      while (newSize &gt; 1) { //newindex가 1일때, 값을 비교하는 인덱스의 위치가 0이므로, 루프를 종료하게됨.
          int lastSwappedIndex = 0;
          for (int j = 0; j &lt; newSize - 1; j++) {
              if (arr1[j] &gt; arr1[j + 1]) { // 왼쪽 값이 크다면 수행
                  // Swap
                  temp = arr1[j];
                  arr1[j] = arr1[j + 1];
                  arr1[j + 1] = temp;
                  lastSwappedIndex = j + 1; // 마지막 수행 인덱스 위치 기록
              }
          }
          newSize = lastSwappedIndex;  // 다음 루프는 마지막 교환 이전까지만 수행
      }
  }

  int main() {
      int* arr;
      int* arr1;
      srand(0); // 난수 시드 초기화

      clock_t start, end, new_start, new_end;      // 시간 측정 변수 선언
      double duration, new_duration;         // 경과 시간(초)

      // 동적 메모리로 정수 배열 할당
      arr = (int*)malloc(sizeof(int) * SIZE);
      arr1 = (int*)malloc(sizeof(int) * SIZE);

      if (arr == NULL &amp;&amp; arr1 == NULL) {
          printf(&quot;메모리 할당 실패\n&quot;);
          return 1;
      }

      // 난수로 arr 배열 초기화
      for (int i = 0; i &lt; SIZE; i++) {
          arr[i] = ((rand() &lt;&lt; 15) | rand()) % (SIZE + 1);
      }

      // arr 배열을 arr1 배열로 복사
      for (int i = 0; i &lt; SIZE; i++) {
          arr1[i] = arr[i];
      }
      printf(&quot;데이터 준비 끝\n&quot;);

      // 정렬 전 앞 10개 출력
      printf(&quot;정렬 전 1~10 : &quot;);
      for (int i = 0; i &lt; 10; i++) {
          printf(&quot;%d &quot;, arr[i]);
      }
      printf(&quot;\n&quot;);

      // 정렬 전 앞 10개 출력
      printf(&quot;정렬 전 1~10 : &quot;);
      for (int i = 0; i &lt; 10; i++) {
          printf(&quot;%d &quot;, arr1[i]);
      }
      printf(&quot;\n&quot;);

      start = clock();         // 정렬 시작 직전 시간 저장
      bubbleSort(arr, SIZE);
      end = clock();           // 정렬 완료 직후 시간 저장

      new_start = clock();
      new_bubbleSort(arr1, SIZE);
      new_end = clock();

      duration = (double)(end - start) / CLOCKS_PER_SEC; // 초 단위로 변환
      new_duration = (double)(new_end - new_start) / CLOCKS_PER_SEC; // 초 단위로 변환

      // 정렬 후 앞 10개 출력
      printf(&quot;정렬 후 1~10 : &quot;);
      for (int i = 0; i &lt; 10; i++) {
          printf(&quot;%d &quot;, arr[i]);

      }
      printf(&quot;\n&quot;);

      // 정렬 후 앞 10개 출력
      printf(&quot;정렬 후 1~10 : &quot;);
      for (int i = 0; i &lt; 10; i++) {
          printf(&quot;%d &quot;, arr1[i]);

      }
      printf(&quot;\n&quot;);

      // 정렬 후 마지막 10개 출력
      printf(&quot;정렬 후 %d~%d : &quot;, SIZE - 10, SIZE);
      for (int i = SIZE - 10; i &lt; SIZE; i++) {
          printf(&quot;%d &quot;, arr[i]);
      }
      printf(&quot;\n&quot;);

      // 정렬 후 마지막 10개 출력
      printf(&quot;정렬 후 %d~%d : &quot;, SIZE - 10, SIZE);
      for (int i = SIZE - 10; i &lt; SIZE; i++) {
          printf(&quot;%d &quot;, arr1[i]);
      }
      printf(&quot;\n&quot;);

      printf(&quot;bubble sort 50만개 소요 시간: %f초\n&quot;, duration);

      printf(&quot;최적화 bubble sort 50만개 소요 시간: %f초\n&quot;, new_duration);

      // 동적 메모리 해제
      free(arr);    
      free(arr1);

      return 0;
  }
