<h2 id="시스템-콜system-call이란">시스템 콜(System Call)이란?</h2>
<p>사용자 프로그램(User Program)이 운영체제 커널(OS Kernel)의 기능을 요청하는 공식적인 인터페이스로, 사용자가 직접 하드웨어를 건드리지 않으면서 커널에게 대신 작업을 요청하는 방식이다.</p>
<blockquote>
<p>파일 읽기
파일 생성
네트워크 통신
프로세스 생성
메모리 할당
...</p>
</blockquote>
<p>위 작업은 OS 커널만 할 수 있는 권한작업인데, 일반적인 프로그램은 하드웨어에 직접 접근할 수 없으므로 커널에게 시스템 콜 방식으로 요청합니다.</p>

<h2 id="copyc-코드">copy.c 코드</h2>
<pre><code class="language-c">#include &lt;unistd.h&gt;     /* 유닉스 표준(UNIX Standard) 시스템 콜을 위한 헤더 파일 */
#include &lt;fcntl.h&gt;
#include &lt;stdio.h&gt;      /* perror() 함수 */
#include &lt;sys/stat.h&gt;
#include &lt;sys/types.h&gt;

int main(int argc, char **argv)
{
    int n, in, out;
    char buf[1024];

    /* 명령행 인수로 복사할 파일명이 없는 경우에 에러를 출력하고 종료한다. */
    if (argc &lt; 3) {
        write(2, &quot;Usage : copy file1 file2\n&quot;, 25);
        return -1;
    }

    /* 복사의 원본이 되는 파일을 읽기 모드로 연다. */
    if ((in = open(argv[1], O_RDONLY)) &lt; 0) {
        perror(argv[1]);
        return -1;
    }

    /* 복사할 결과 파일을 쓰기 모드(새로운 파일 생성 | 기존에 파일 내용 지움)로 연다. */
    if ((out = open(argv[2], O_WRONLY|O_CREAT|O_TRUNC, S_IRUSR|S_IWUSR)) &lt; 0) {
        perror(argv[2]);
        return -1;
    }

    /* 원본 파일의 내용을 읽어서 복사할 파일에 쓴다. */
    while ((n = read(in, buf, sizeof(buf))) &gt; 0)
        write(out, buf, n);

    /* 열린 파일들을 닫는다. */
    close(out);
    close(in);

    /* 프로그램의 정상 종료 시 0을 반환한다. */
    return 0;
}</code></pre>
<p><code>open()</code> , <code>read()</code> , <code>write()</code> , <code>close()</code> 는 각각 파일 열기, 읽기, 쓰기, 닫기에 해당하는 시스템 콜에 해당합니다. 위 함수를 쓰기 위해 <code>fcntl.h</code>(open)와 <code>unistd.h</code>(read, write, close)를 include 해줍니다.</p>
<p>main 함수의 인자를 살펴보면, <code>main(int argc, char *argv[])</code> 입니다.
copy라는 실행 파일로 예를 하나 들면서 설명을 하면 </p>
<pre><code class="language-bash">./copy  a.txt  b.txt</code></pre>
<ul>
<li><code>./copy</code> : argc = 1</li>
<li><code>a.txt</code> : argc = 2</li>
<li><code>b.txt</code> : argc = 3</li>
</ul>
<hr />
<ul>
<li><code>./copy</code> : argv[0]</li>
<li><code>a.txt</code> : argv[1]</li>
<li><code>b.txt</code> : argv[2]</li>
</ul>
<p>이런 느낌입니다. 사실 <em>argv[] = *</em>argv와 같습니다.</p>
<ul>
<li>write 함수에서 <code>write(2, ...)</code> 2는 stderr를 의미합니다.</li>
<li><code>in = open(argv[1], O_RDONLY)</code> 에서 <ul>
<li>argv[1] :  복사할 원본 파일</li>
<li>O_RDONLY : 읽기 전용</li>
</ul>
</li>
</ul>
<p>실패하면 perror(argv[1]); 을 실행합니다.</p>
