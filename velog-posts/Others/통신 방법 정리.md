<h3 id="1-직렬-vs-병렬-통신">1. 직렬 vs 병렬 통신</h3>
<p>일단 통신은 크게 직렬(Serial) 통신, 병렬(parallel) 통신으로 구분할 수 있습니다.</p>
<ul>
<li>직렬 통신 : 1개의 라인만을 사용, 1클럭당 1개 데이터(1비트) 전송</li>
<li>병렬 통신 : 여러개의 라인을 사용, 1클럭당 여러 개의 데이터를 전송하는 방식으로, 8비트, 16비트, 32비트, 64비트의 데이터 전송 방법이 많이 사용됩니다.</li>
</ul>
<p>여러 개의 데이터를 한꺼번에 보낸다고 하니 병렬 통신이 좋아보이지만, 병렬 통신을 진행할 경우 필요한 라인이 많기 때문에 칩의 크기가 커지고, 마이크로 프로세서에 내장되는 통신 포트에 필요한 핀 수가 상대적으로 많습니다.</p>
<p>따라서 대부분의 마이크로프로세서, IC 칩은 데이터 통신 용으로 병렬 통신보다는 직렬을 많이 이용하는 편입니다.</p>
<blockquote>
<h3 id="직렬-통신의-장점">직렬 통신의 장점</h3>
<ul>
<li>칩의 크기가 소형화(통신 포트에 필요한 핀 수 감소되기 때문)</li>
<li>가격이 저렴해짐</li>
</ul>
</blockquote>
<p>직렬 통신의 예시</p>
<ul>
<li>RS-232C, RS-422, RS-485</li>
<li>USB, TCP/IP(인터넷), CAN</li>
<li>I2C, SPI</li>
</ul>

<h3 id="2-단방향-vs-반이중-vs-전이중-통신">2. 단방향 vs 반이중 vs 전이중 통신</h3>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/e792c4e1-bcda-497f-8529-dbd3d2fda7fd/image.png" /></p>
<p>그림과 같습니다.</p>
<ul>
<li>단방향 : A-&gt;B</li>
<li>반이중 : A-&gt;B, B-&gt;A (동시에 못 보냄)</li>
<li>전이중: A&lt;=&gt;B (동시에 보낼 수 있음)</li>
</ul>

<h3 id="3-비동기-vs-동기-통신">3. 비동기 vs 동기 통신</h3>
<p>비동기 통신과 동기 통신의 큰 차이는 <strong>클럭의 유무</strong> 라고 생각합니다.</p>
<p>비동기 통신의 경우, 송수신단이 약속된 속도(Baud rate)에 맞춰 시작과, 종료 신호를 정합니다. 예를 들어 UART의 경우, <code>[Start bit][Data][Stop Bit]</code>를 한꺼번에 보내서 데이터를 보내겠다, 데이터를 다 보냈다를 알려줍니다. 수신기는 Start Bit를 감지하는 순간부터 내부 타이머로 비트 타이밍을 계산하여 수신하는데, 속도 설정(baud rate)이 다르거나, 버퍼가 넘치면 문제가 발생할 수 있습니다. 구조가 단순해서 구현이 쉽다는 장점이 있으나, 속도가 느리고 오차에 민감하다는 단점을 갖습니다.</p>
<p>동기 통신의 경우, 송수신측이 공통 클럭을 공유하거나 별도의 클럭 신호를 통해 타이밍을 정확히 맞추는것이 가장 큰 차이점입니다. 데이터 전송 동안 클록을 함께 보내서 데이터를 지금 보낼거야, 여기까지 데이터 다 보냈어! 라고 타이밍을 동기화한다고 생각하면 됩니다. 비동기 통신과 다르게 클럭에 맞춰 데이터를 전송하므로 수신 타이밍 관련해서 문제 일어날 일이 적은 편입니다. 속도가 빠르고 안정적이라는 특징이 있으나, 회로등의 구현이 복잡한 편입니다.</p>

<h3 id="4-uart비동기-통신">4. UART(비동기) 통신</h3>
<h4 id="41-uart-란-">4.1 UART 란 ?</h4>
<p>UART(Universal Asynchronous Receiver/Transmitter)는 범용 비동기 송수신기 라고 해석할 수 있습니다.</p>
<p> 데이터를 직렬로, 또는 병렬로 변환시켜주는 직렬 통신 모듈로, PC, 마이크로 프로세서와 주변 장치들 간에 직렬(Serial) 포트를 이용한 통신에 주로 사용됩니다. 요즘 나오는 대부분의 MCU에는 UART를 내장하고 있는 경우가 많습니다.</p>
<h4 id="42-uart의-구조">4.2) UART의 구조</h4>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/249ba754-7a0d-493f-8750-03f30adaa826/image.png" /></p>
<p>일반적으로 UART의 구조는 다음과 같습니다. RX, TX의 핀이 필요하고, Rx는 데이터를 받는 역할, TX는 데이터를 보내는 역할을 하므로 두 보드간의 통신을 진행한다고 하면 </p>
<pre><code class="language-c">A의 TX -&gt; B의 RX
B의 TX -&gt; A의 RX</code></pre>
<p>와 같이 하드웨어 배선을 진행해야 합니다.</p>
<h4 id="43-uart의-데이터-프레임-구성">4.3) UART의 데이터 프레임 구성</h4>
<p>UART는 송수신을 데이터 프레임 단위로 진행합니다. 하지만 비동기 통신 방식이기 때문에 Start Bit, Stop Bit가 한 프레임 안에 포함되어 있다는 특징이 있습니다.</p>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/502b6688-8cd0-4b96-9c33-33098ab1d909/image.png" /></p>
<ul>
<li><code>1bit</code> : 시작(start) 비트</li>
<li><code>5~8bit</code> : 비트의 데이터(data) 비트</li>
<li><code>1bit</code> : 패리티(parity) 비트 -&gt; 오류 검출 용, 선택 사항</li>
<li><code>1~2bit</code> : 정지(stop) 비트</li>
</ul>
<p>위와 같이 한 프레임이 구성되어 있습니다.</p>
<h4 id="44-baud-rate전송-속도">4.4) Baud Rate(전송 속도)</h4>
<p>보레이트는 데이터의 전송 속도를 나타내는 말로, 9,600bps, 115,200bps를 많이 사용합니다.
<code>bps : bit per second</code>  말 그대로 1초에 보내는 비트 수를 의미합니다. UART에서 한 프레임 기준 최소 <code>7bit</code> ~ 최대 <code>12bit</code> 로 구성되어 있기 때문에, 115,200bps를 사용한다고 해도 실제로 보내는 payload(의미 있는 데이터)의 개수는 115,200개 보다 적습니다.</p>
<ul>
<li>1bps : 1초에 1bit 전송</li>
<li>9,600bps : 1초에 9,600bit 전송</li>
<li>115,200bps : 1초에 115,200bit 전송</li>
</ul>
<h4 id="45-uart-정리">4.5) UART 정리</h4>
<ul>
<li>비동기 직렬 통신 방법</li>
<li>Rx 통해 데이터를 받고, Tx를 통해 데이터를 전송</li>
<li>한 데이터 프레임은 <code>[Start bit][Data][Parity bit(옵션)][Stop bit]</code> 으로 구성</li>
<li>송수신기에 같은 Baud Rate를 설정해줘야함.</li>
</ul>

<h3 id="5-i2c동기-통신">5. I2C(동기) 통신</h3>
<h4 id="51-i2c-란-">5.1) I2C 란 ?</h4>
<p>I2C(Inter-Integrated Circuit)으로 IC 사이에서 통신 링크를 제공하는 양방향 2wire 직렬 버스입니다. 실제로는 아이 스퀘어 씨로 읽는다고 합니다.</p>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/d38a7338-b05f-45eb-8d44-b69b66f5cd48/image.png" /></p>
<ul>
<li>SDA(데이터) : 데이터를 주고 받기 위한 선</li>
<li>SCL(클록) : 타이밍을 동기화 하기 위한 클럭 선</li>
</ul>
<h4 id="52-i2c의-구조">5.2) I2C의 구조</h4>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/d73c4149-0440-4887-9437-afefe2b6e0e6/image.png" /></p>
<p>I2C는 여러 개의 마스터와, 여러 개의 슬레이브로 구성이 가능합니다. 슬레이브는 127개까지 구성이 가능합니다.</p>
