<h3 id="핵심-개념-왜-대기sleep-상태가-필요한가">핵심 개념: 왜 대기(Sleep) 상태가 필요한가</h3>
<p>CPU는 한 번에 하나의 프로세스만 실행할 수 있어서 OS가 여러 프로세스를 번갈아 실행시키는데, 이를 <strong>스케줄링</strong>이라고 한다.</p>
<p>대기 상태 없이 <strong>실행 ↔ 준비</strong> 만 존재한다면?</p>
<ul>
<li>키보드 입력 대기, 네트워크 응답 대기 중인 프로세스도 CPU 시간을 똑같이 배분받아 낭비</li>
<li>실제로 CPU가 필요한 프로세스(ex. 동영상 재생)가 충분한 시간을 못 받아 버벅임</li>
</ul>
<p>따라서 &quot;어차피 기다려야 하는&quot; 프로세스는 <strong>대기 상태</strong>로 빠지고,<br />CPU는 실행이 필요한 프로세스에게 집중하게 된다.</p>

<h3 id="지연-상태-swap">지연 상태 (Swap)</h3>
<p>메모리가 부족할 때 준비/대기 중인 프로세스를 디스크로 내보내는 것 (Swap-out).<br />메모리 여유가 생기면 다시 불러온다 (Swap-in).<br />현대 시스템에서는 메모리가 충분해 자주 발생하지 않는다.</p>
