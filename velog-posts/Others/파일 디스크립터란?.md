<h2 id="파일-디스크립터">파일 디스크립터?</h2>

저 수준 파일 입출력 함수에게 소켓의 파일 디스크립터를 전달하면, 소켓을 대상으로 입출력 진행</p>

<p>sockfd에 생성한 소켓을 저장하면, OS가 sockfd에 3번이라는 번호를 발급합니다.
write, read, close는 어떤 소켓에 작업을 할 것인지에 따라 알맞는 sockfd 번호를 넣어주면 됩니다.</p>
<pre><code class="language-c">int sockfd = socket(PF_INET, SOCK_STREAM, 0);
// sockfd = 3  (OS가 발급한 번호)

write(sockfd, buf, len);  // &quot;3번한테 데이터 써&quot;
read(sockfd, buf, len);   // &quot;3번한테서 데이터 읽어&quot;
close(sockfd);            // &quot;3번 반납&quot;</code></pre>
<p>파일 디스크립터에 집중하여, TCP 서버및 클라이언트에 관한 함수들을 다시 정리해보겠습니다.</p>
<pre><code class="language-c">int socket(int domain, int type, int protocol); // fd 발급

#include &lt;sys/socket.h&gt;

int bind(int sockfd, struct sockaddr* myaddr, socklen_t addrlen);
int listen(int sockfd, int backlog);
int accept(int sockfd, struct sockaddr* addr, socklen_t* addrlen); // 새 fd 반환
int connect(int sockfd, const struct sockaddr* servaddr, socklen_t addrlen);

#include &lt;unistd.h&gt;
int open(const char* path, int flag);    // 성공 시 fd 반환
int close(int fd);    // open() 과 함께, fd 반납
ssize_t write(int fd, const void* buf, size_t nbytes);
ssize_t read(int fd, void* vuf, sizet nbytes);</code></pre>
