<h2 id="머신러닝이란-무엇인가">머신러닝이란 무엇인가?</h2>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/e70e9c66-98dd-49e5-85d0-bd6c908fb782/image.png" /></p>
<p>머신러닝(Machine Learning)은 컴퓨터가 명시적으로 프로그래밍되지 않아도 데이터로부터 스스로 학습하고 예측하는 능력을 갖추도록 하는 인공지능의 한 분야입니다.</p>
<p>전통적인 프로그래밍은 개발자가 모든 규칙을 직접 코드로 작성했다면, 머신러닝은 대량의 데이터를 통해 컴퓨터가 스스로 패턴과 규칙을 찾아냅니다.</p>
<blockquote>
<p>머신러닝의 핵심은 <strong>데이터</strong>입니다. 좋은 데이터가 좋은 모델을 만듭니다.</p>
</blockquote>
<hr />
<h2 id="ai는-어떻게-결정을-내리는가">AI는 어떻게 결정을 내리는가?</h2>
<p>AI가 결정을 내리는 방식을 직관적인 예시로 이해해 보겠습니다.</p>
<p>&quot;오늘 공원에 가야 할까?&quot;라는 질문을 생각해 봅시다. 사람은 여러 조건을 따져 결정을 내립니다.</p>
<ul>
<li>지금 비가 오나요?</li>
<li>오늘 일기예보가 어떻게 되나요?</li>
<li>우비를 갖고 있나요?</li>
<li>우산을 갖고 있나요?</li>
</ul>
<p>이처럼 여러 입력 조건(요인)을 종합적으로 고려해 최종 판단을 내리는 과정을 AI도 동일하게 수행합니다. 이 과정을 수학적으로 모델링한 것이 바로 <strong>퍼셉트론</strong>입니다.</p>
<hr />
<h2 id="퍼셉트론perceptron">퍼셉트론(Perceptron)</h2>
<h3 id="퍼셉트론의-등장">퍼셉트론의 등장</h3>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/e1d06555-d0c1-4ec0-a112-00825e933694/image.png" /></p>
<p>퍼셉트론은 <code>perception(인식)</code>과 <code>neuron(뉴런)</code>의 합성어로, 인간의 신경 세포(뉴런)가 작동하는 방식을 수학적으로 모델링한 개념입니다.</p>
<p>뉴런은 일정 수준 이상의 입력 신호를 받아야 출력 신호가 발생합니다. 퍼셉트론은 이 과정을 그대로 모방합니다.</p>
<h3 id="퍼셉트론의-구성-요소">퍼셉트론의 구성 요소</h3>
<p>퍼셉트론은 세 가지 핵심 요소로 구성됩니다.</p>
<p><strong>입력(Inputs)</strong>
<img alt="" src="https://velog.velcdn.com/images/mommers/post/b2772379-fe4f-4ac2-9fb8-fdbd5ac84bbd/image.png" /></p>
<p>각 조건이나 특성(Feature)이 입력값으로 들어옵니다. 공원 예시에서는 &quot;우비 보유 여부&quot;, &quot;날씨 화창 여부&quot; 등이 입력에 해당합니다.</p>
<p><strong>가중치(Weights)</strong>
<img alt="" src="https://velog.velcdn.com/images/mommers/post/e2c2afc7-7888-4bb6-962d-ff9e4f1838cf/image.png" /></p>
<p>각 입력의 중요도를 나타내는 값입니다. 더 중요한 요소일수록 더 큰 가중치를 부여합니다. 예를 들어 &quot;현재 날씨가 화창한가(가중치 3.0)&quot;는 &quot;우산 보유 여부(가중치 1.0)&quot;보다 더 중요한 요소로 판단될 수 있습니다.</p>
<p><strong>편향(Bias)</strong>
<img alt="" src="https://velog.velcdn.com/images/mommers/post/ee629243-5b2c-4a70-aedd-11995120252c/image.png" /></p>
<p>퍼셉트론이 얼마나 쉽게 활성화될지를 결정하는 값입니다. YES 또는 NO의 결정을 내리기 위한 기준점 역할을 합니다.</p>
<h3 id="퍼셉트론의-동작-방식">퍼셉트론의 동작 방식</h3>
<p>퍼셉트론은 모든 입력값에 각각의 가중치를 곱한 뒤 더하고, 여기서 편향을 빼서 최종 출력값을 계산합니다.</p>
<pre><code>Output = (x1 * w1) + (x2 * w2) + ... + (xn * wn) - bias</code></pre><blockquote>
<p>계산 결과가 <strong>양수</strong>이면 YES(1), <strong>음수</strong>이면 NO(0)를 출력합니다. 0을 임계값으로 사용하는 것입니다.</p>
</blockquote>

<h2 id="인공신경망의-발전-역사">인공신경망의 발전 역사</h2>
<h3 id="단층-퍼셉트론의-한계-1969">단층 퍼셉트론의 한계 (1969)</h3>
<p>단층 퍼셉트론은 <strong>선형 분리(Linearly Separable)</strong> 문제는 잘 해결하지만, <strong>비선형 분리(Non-linearly Separable)</strong> 문제는 해결할 수 없다는 것이었습니다. 대표적인 예가 XOR 연산 문제입니다.</p>
<h3 id="다층-퍼셉트론의-등장-1986">다층 퍼셉트론의 등장 (1986)</h3>
<p>단층 퍼셉트론의 한계로, 다층 퍼셉트론이 등장하였습니다.
NAND, OR, AND 연산자를 조합하여 XOR 문제를 해결하는 방식으로 비선형 분리 문제를 극복할 수 있었습니다.</p>
<p>아울러 오차를 출력층에서 입력층 방향으로 역으로 전파시켜 각 층의 가중치와 편향을 자동으로 조정하는 <strong>오차 역전파 알고리즘(Back Propagation Algorithm)</strong> 이 도입되었습니다. </p>
<h3 id="mlp의-한계">MLP의 한계</h3>
<p>층이 많아질수록 학습이 어려워지는 문제들이 등장하였습니다.</p>
<ul>
<li><strong>Vanishing Gradient</strong>: 기울기가 소실되어 최적값이 아닌 지점에서 학습이 멈추는 문제</li>
<li><strong>Overfitting(과적합)</strong>: 고차원 데이터에서 훈련 데이터에만 지나치게 맞춰지는 문제</li>
<li><strong>느린 학습 속도</strong>: 층이 깊어질수록 학습 시간이 크게 증가하는 문제</li>
</ul>
<blockquote>
<p>이러한 한계들을 극복하기 위한 연구가 이어지며 현대의 딥러닝(Deep Learning)으로 발전하게 됩니다.</p>
</blockquote>
<hr />
<h2 id="머신러닝의-학습-방식">머신러닝의 학습 방식</h2>
<p>머신러닝은 크게 <strong>지도 학습</strong>, <strong>비지도 학습</strong>, <strong>강화 학습</strong> 세 가지 방식으로 분류됩니다.</p>
<h3 id="지도-학습-supervised-learning">지도 학습 (Supervised Learning)</h3>
<p>정답(레이블)이 있는 데이터를 사용하여 학습합니다. 입력과 출력 사이의 관계를 학습해 새로운 데이터에 대한 예측을 수행합니다.</p>
<blockquote>
<p>지도 학습은 <strong>독립변수(설명변수)</strong>와 종속변수(목적변수) 간의 관계를 학습하여 인식, 분류, 진단, 예측 등의 문제 해결에 적합합니다.</p>
</blockquote>
<p>예측하려는 값의 형태에 따라 두 가지로 나뉩니다. 
데이터를 정해진 범주 중 하나로 구분하는 분류(Classification), 연속적인 수치를 예측하는 회귀(Regression) 가 있습니다. </p>
<p>각 알고리즘의 원리와 특성은 이후 글에서 자세히 다루겠습니다.</p>
<h3 id="비지도-학습-unsupervised-learning">비지도 학습 (Unsupervised Learning)</h3>
<p>정답(레이블) 없이 데이터 자체의 패턴이나 구조를 찾아냅니다. 데이터를 비슷한 것끼리 묶거나 숨겨진 특징을 발견하는 데 활용됩니다.</p>
<p>대표적인 방법으로는 비슷한 데이터끼리 묶는 군집화(Clustering), 데이터의 특징을 더 적은 변수로 압축하는 차원 축소(Dimensionality Reduction) 가 있습니다.</p>
<blockquote>
<p>비지도 학습은 레이블이 없으므로 일반적인 정확도(Accuracy)로 평가하기 어렵습니다. 대신 데이터의 요약 정보를 통해 전체 데이터가 가진 특징을 발견하는 데 초점을 맞춥니다</p>
</blockquote>
<h3 id="강화-학습-reinforcement-learning">강화 학습 (Reinforcement Learning)</h3>
<p>에이전트(Agent)가 환경(Environment)과 상호작용하며 보상(Reward)을 최대화하는 방향으로 스스로 학습합니다. 정해진 정답 데이터 없이, 행동의 결과로 받는 보상 신호를 기반으로 최적의 행동 방식을 익혀나갑니다.</p>
<p>게임 AI, 로봇 제어, 자율주행처럼 순차적인 의사결정이 필요한 분야에서 활발히 활용됩니다.</p>
<blockquote>
<p>지도 학습과 비지도 학습이 데이터를 보고 학습한다면, 강화 학습은 직접 행동하며 학습합니다.</p>
</blockquote>
<hr />
<h2 id="머신러닝-알고리즘의-종류">머신러닝 알고리즘의 종류</h2>
<p>머신러닝에는 수십 가지 이상의 알고리즘이 존재하며, 문제의 유형에 따라 적합한 알고리즘을 선택합니다. 지도 학습은 크게 <strong>분류(Classification)</strong>와 <strong>회귀(Regression)</strong>로 나뉩니다.</p>
<h3 id="분류-classification">분류 (Classification)</h3>
<p>데이터를 유한 개의 클래스로 나누는 작업입니다. 예를 들어 이메일이 스팸인지 아닌지, 사진 속 동물이 고양이인지 개인지를 판단하는 것이 분류 문제에 해당합니다.</p>
<p>대표적인 분류 알고리즘으로는 K-최근접 이웃(KNN), 서포트 벡터 머신(SVM), 결정 트리(Decision Tree), 로지스틱 회귀(Logistic Regression), 나이브 베이즈(Naive Bayes) 등이 있습니다.</p>
<h3 id="회귀-regression">회귀 (Regression)</h3>
<p>연속적인 수치를 예측하는 작업입니다. 기온에 따른 아이스크림 판매량 예측이나 배달 거리에 따른 배달 시간 예측 등이 회귀 문제에 해당합니다.</p>
<p>대표적인 회귀 알고리즘으로는 선형 회귀(Linear Regression), 회귀 트리(Regression Tree), 랜덤 포레스트 회귀(Random Forest Regression), 서포트 벡터 머신(SVM) 등이 있습니다.</p>
<hr />
<h2 id="머신러닝-파이프라인">머신러닝 파이프라인</h2>
<p>실제 머신러닝 프로젝트는 단순히 모델을 학습시키는 것에 그치지 않습니다. 문제 정의부터 모델 배포까지 일련의 단계가 순서대로 진행되며, 이를 <strong>머신러닝 파이프라인</strong> 이라고 합니다.</p>
<pre><code>문제 정의 → 데이터 수집 → 데이터 전처리 → 모델 선택 및 학습 → 평가 → 배포</code></pre><p><strong>1. 문제 정의</strong></p>
<p>풀고자 하는 문제가 분류인지, 회귀인지, 군집화인지를 명확히 합니다. 문제 유형에 따라 이후 모든 단계의 방향이 결정됩니다.</p>
<p><strong>2. 데이터 수집</strong></p>
<p>모델 학습에 필요한 데이터를 수집합니다. 데이터의 양과 질이 모델 성능에 직접적인 영향을 미칩니다.</p>
<p><strong>3. 데이터 전처리</strong></p>
<p>수집한 데이터를 모델이 학습하기 적합한 형태로 가공합니다. 결측치 처리, 이상치 제거, 정규화(Normalization), 피처 엔지니어링 등이 이 단계에 포함됩니다.</p>
<blockquote>
<p>실제 머신러닝 프로젝트에서 데이터 전처리에 소요되는 시간은 전체 작업의 70~80%에 달하는 경우가 많습니다.</p>
</blockquote>
<p><strong>4. 모델 선택 및 학습</strong></p>
<p>문제 유형과 데이터 특성에 맞는 알고리즘을 선택하고 학습을 진행합니다. 하나의 알고리즘으로 끝나는 경우보다 여러 모델을 비교하며 최적의 모델을 찾아가는 과정이 일반적입니다.</p>
<p><strong>5. 평가</strong></p>
<p>학습된 모델이 새로운 데이터에 대해 얼마나 잘 예측하는지를 평가 지표(정확도, 정밀도, 재현율, MSE 등)를 통해 측정합니다.</p>
<p><strong>6. 배포</strong></p>
<p>평가를 통해 검증된 모델을 실제 서비스나 시스템에 적용합니다.</p>
