// the setup function runs once when you press reset or power the board
void setup() {
  // initialize digital pin LED_BUILTIN as an output.
  pinMode(LED_BUILTIN, OUTPUT);

// the loop function runs over and over again forever
void loop() {
  digitalWrite(LED_BUILTIN, HIGH);  // turn the LED on (HIGH is the voltage level)

  delay(1000);                      // wait for a second

<li><p>아두이노 우노 PlatformIO에서 어셈블리(Assembly) 파일 얻는 방법</p>
<p>  PlatformIO에서 C/C++ 프로젝트의 어셈블리 코드를 확인하려면, 아래와 같은 방법을 활용할 수 있습니다.</p>
<h3 id="1-platformioini-설정">1. <code>platformio.ini</code> 설정</h3>
<p>  <code>platformio.ini</code> 파일에서 <code>build_flags</code> 옵션을 활용해 컴파일러가 어셈블리 파일을 생성하도록 할 수 있습니다.</p>
<pre><code>  [env:uno]
  platform = atmelavr
  board = uno
  framework = arduino
  build_flags =
      -save-temps=obj
      -fverbose-asm  // 이쪽으로 출력을 내보내줌</code></pre><p>// 수정 후 다시 빌드</p>
<ul>
<li><p><code>save-temps=obj</code> : 빌드 디렉토리에 중간 산출물 파일(<code>.s</code>, <code>.i</code>, <code>.ii</code> 등)을 생성합니다.</p>
</li>
<li><p><code>fverbose-asm</code> : 어셈블리 파일 내에 추가 정보를 포함하도록 합니다[1][2].</p>
<h3 id="2-빌드-후-어셈블리-파일-위치">2. 빌드 후 어셈블리 파일 위치</h3>
<p>컴파일 후 <code>.pio/build/[환경명]/</code> 폴더로 이동하면, <code>.s</code> 파일이 생성되어 있습니다.</p>
</li>
<li><p>예시 경로: <code>.pio/build/uno/src/main.cpp.s</code></p>
<h3 id="3-전체-프로젝트-어셈블리-추출-objdump-활용">3. 전체 프로젝트 어셈블리 추출 (objdump 활용)</h3>
<p>컴파일이 끝난 후, <code>.elf</code> 파일을 <code>objdump</code>로 디스어셈블 하면 전체 어셈블리 코드를 한 파일로 정리할 수 있습니다.</p>
<pre><code class="language-c">C:\Users\hanki\.platformio\packages\toolchain-atmelavr\bin\avr-objdump.exe   </code></pre>
<pre><code class="language-bash">cd .pio/build/uno
avr-objdump -S -d firmware.elf &gt; firmware.s

C:\Users\hanki\.platformio\packages\toolchain-atmelavr\bin\avr-objdump  -S -d firmware.elf &gt; firmware.s</code></pre>
</li>
<li><p><code>firmware.s</code>에 어셈블리 코드와 C 소스가 병기되어 저장됩니다[2][1][3].</p>
<h3 id="4-추가-팁-post_build-스크립트-활용">4. 추가 팁: post_build 스크립트 활용</h3>
<p>빌드 후 자동으로 어셈블리 listing 파일을 생성하고 싶을 경우, <code>post_build.py</code> 커스텀 스크립트를 활용할 수 있습니다.</p>
</li>
<li><p><code>platformio.ini</code>에 다음 추가:</p>
<pre><code>  extra_scripts = post_build.py
</code></pre></li>
<li><p>루트 폴더에 <code>post_build.py</code> 파일 작성:</p>
<pre><code class="language-python">  Import(&quot;env&quot;)
  def after_build(source, target, env):
      objdump = env.subst(&quot;${OBJCOPY}&quot;).replace(&quot;objcopy&quot;, &quot;objdump&quot;)
      src_elf = env.subst(&quot;${BUILD_DIR}/${PROGNAME}.elf&quot;)
      env.Execute(f&quot;{objdump} -S -C -d {src_elf} &gt; ${PROGNAME}.lst&quot;)
  env.AddPostAction(&quot;${BUILD_DIR}/${PROGNAME}.elf&quot;, after_build)
</code></pre>
</li>
<li><p>빌드할 때마다 자동으로 리스팅 파일이 생성됩니다.</p>
</li>
</ul>
