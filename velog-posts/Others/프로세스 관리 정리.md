<h2 id="프로세스">프로세스?</h2>
<p>현재 시스템에서 실행중인 프로그램을 말한다.</p>
<ul>
<li>프로세스는 부모 - 자식 관계를 가지고 있고, 자식은 또 다른 자식을 가질 수 있다.</li>
<li>모든 프로세스는 부모 프로세스를 가지고있다.</li>
<li>자식 프로세스는 할 일이 끝나면 부모 프로세스에 결과를 돌려주고 종료</li>
</ul>
<h2 id="프로세스의-번호">프로세스의 번호?</h2>
<ul>
<li>각 프로세스는 고유 번호 <code>PID</code> 를 가진다.</li>
<li><code>PID</code> 는 시스템의 전원이 꺼지기 전까지, 서로 겹치지 않는다.</li>
</ul>
<hr />
<h2 id="프로세스-목록-명령어-ps-정리">프로세스 목록 명령어 <code>ps</code> 정리</h2>
<p>현재 실행중인 프로세스의 목록을 보는 명령 : <code>ps</code> </p>
<ul>
<li><strong>기능</strong> 현재 실행 중인 프로세스의 정보를 출력한다.</li>
<li><strong>형식</strong> <code>ps [옵션]</code></li>
<li><strong>옵션</strong></li>
</ul>
<p>  <strong>〈유닉스 옵션〉</strong></p>
<ul>
<li><code>-e</code> : 시스템에서 실행 중인 모든 프로세스의 정보를 출력한다.</li>
<li><code>-f</code> : 프로세스의 자세한 정보를 출력한다.</li>
<li><code>-u uid</code> : 특정 사용자에 대한 모든 프로세스의 정보를 출력한다.</li>
<li><code>-p pid</code> : pid로 지정한 특정 프로세스의 정보를 출력한다.</li>
</ul>
<p>  <strong>〈BSD 옵션〉</strong></p>
<ul>
<li><code>a</code> : 터미널에서 실행한 프로세스의 정보를 출력한다.</li>
<li><code>u</code> : 프로세스 소유자 이름, CPU 사용량, 메모리 사용량 등 상세 정보를 출력한다.</li>
<li><code>x</code> : 시스템에서 실행 중인 모든 프로세스의 정보를 출력한다.</li>
</ul>
<p>  <strong>〈GNU 옵션〉</strong></p>
<ul>
<li><code>--pid PID 목록</code> : 목록으로 지정한 특정 PID의 정보를 출력한다.</li>
</ul>
<ul>
<li><strong>사용 예</strong> <code>ps</code> &nbsp;&nbsp;&nbsp;&nbsp; <code>ps -ef</code> &nbsp;&nbsp;&nbsp;&nbsp; <code>ps aux</code></li>
</ul>
<hr />
<p>주로 사용하는 함수를 정리해보면,</p>
<ul>
<li><code>ps -ef | grep xxxx</code>  : xxxx가 들어간 프로세스 검색</li>
<li><code>ps -f</code>  : 프로세스의 자세한 정보 출력</li>
<li><code>ps -aux | grep xxxx</code> : 특정 프로세스 검색(<code>ps -ef | grep</code> 과 비슷)</li>
</ul>
<blockquote>
<p><code>ps -ef</code> 는 유닉스 스타일, PPID(부모 PID) 확인 가능
<code>ps aux</code> 는 BSD 스타일, CPU/메모리 사용률 확인 가능</p>
</blockquote>

<h2 id="포그라운드-백그라운드-작업">포그라운드, 백그라운드 작업</h2>
<p>포그라운드 프로세스는 사용자가 입력한 명령에 대한 결과가 출력될 때까지 기다려야 하는 방식으로 처리되고,</p>
<p>백그라운드는 이와 다르게 명령을 실행해두고 백그라운드에서 처리할때까지 포그라운드 영역에서 다른 작업을 진행할 수 있다.</p>
<p>백그라운드 작업으로 실행할 때는 </p>
<pre><code class="language-c">./iot_server 5000 &amp;</code></pre>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/494af01a-1560-4136-b002-d40934951ac1/image.png" /></p>
<p>이런 식으로 &amp;를 뒤에 붙여주면 된다.</p>
<h2 id="jobs--작업-제어-명령어">jobs : 작업 제어 명령어</h2>
<p>백그라운드 작업을 확인할 수 있다.</p>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/86ccea85-658b-48c6-8880-88e616c65966/image.png" /></p>
<p>현재 서버 1개와, 클라이언트 2개를 각각 백그라운드로 돌려 둔 상황이다. jobs 명령어를 통해 백그라운드에서 돌아가고 있는 작업 목록을 확인 가능하다.</p>
<p>맨 아래쪽에 있는 iot_socket.d에서 실행된 <code>./iot_client 127.0.0.1 5000 KYM_LIN &amp;</code> 의 같은 경우, <code>ps -ef | grep iot</code> 명령어에서 아래와 같이 출력되었다.</p>
<pre><code class="language-bash">ubuntu    107053   94211  0 19:19 pts/1    00:00:00 ./iot_server 5000
ubuntu    107626  101079  0 19:21 pts/0    00:00:00 grep --color=auto --exclude-dir=.bzr --exclude-dir=CVS --exclude-dir=.git --exclude-dir=.hg --exclude-dir=.svn iot
[1]-  완료                  ./iot_client 127.0.0.1 5000 KYM_LIN
[2]+  완료                  ./iot_client 127.0.0.1 5000 KYM_LIN</code></pre>
<p>여기서 [1] , [2] 옆의 +, - 는 작업 순서 표시와 관련이 있다.</p>
<ul>
<li>+ : 가장 최근에 접근한 작업</li>
<li>- : + 작업 바로 직전에 접근한 작업</li>
</ul>

<h2 id="작업-전환하기">작업 전환하기</h2>
<table>
<thead>
<tr>
<th>명령</th>
<th>기능</th>
</tr>
</thead>
<tbody><tr>
<td>Ctrl + Z 또는 stop [%작업 번호]</td>
<td>포그라운드 작업을 정지한다 (종료하는 것이 아니라 잠시 중단하는 것이다).</td>
</tr>
<tr>
<td>bg [%작업 번호]</td>
<td>작업 번호가 지시하는 작업을 백그라운드 작업으로 전환한다.</td>
</tr>
<tr>
<td>fg [%작업 번호]</td>
<td>작업 번호가 지시하는 작업을 포그라운드 작업으로 전환한다.</td>
</tr>
</tbody></table>
