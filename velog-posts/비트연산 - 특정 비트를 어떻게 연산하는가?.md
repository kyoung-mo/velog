<h1 id="특정-비트를-1로-설정-⇒-지정된-위치의-비트를-1과-or연산">특정 비트를 1로 설정 ⇒ 지정된 위치의 비트를 1과 |(OR)연산</h1>
<ul>
<li><p>5번 비트를 1로 설정</p>
<pre><code class="language-c">      01010101
  OR  00**1**00000
  ---------------
      01**1**10101  
</code></pre>
</li>
</ul>
<ul>
<li><p>위의 연산을 코드화 한다면</p>
<pre><code class="language-c">  a |= 0b00**1**00000;</code></pre>
</li>
</ul>
<ul>
<li><p>그런데 0b0010_0000은 0x1(0b0000_0001)을 5번 왼쪽 쉬프트한 값과 같다.</p>
<pre><code class="language-c">  a |= 0x1 &lt;&lt;5;</code></pre>
</li>
</ul>
<ul>
<li><p>한번에 여러비트 설정도 가능</p>
<pre><code class="language-c">  a |= (0x1&lt;&lt;5) + (0x1&lt;&lt;3) + (0x1&lt;&lt;2);
  00100000
  00001000
  00000100
  ---
  00101100 (0b2A)</code></pre>
</li>
</ul>
<ul>
<li><p>그런데 3,2번 비트은 연속된 비트이기에 0x3으로 묶을 수 있다.</p>
<pre><code class="language-c">                          a |= (0x1&lt;&lt;5) + (0x3&lt;&lt;2);</code></pre>
</li>
</ul>
<h1 id="특정-비트-클리어">특정 비트 클리어</h1>
<ul>
<li>클리어는 지정된 비트를 0과 &amp;연산한다.0</li>
<li>특정 비트를 1로 설정할 때와 마찬가지로 0을 원하는 위치까지 쉬프트하고 &amp; 연산한다.</li>
</ul>
<blockquote>
<p>0x0으로 자리수를 표현할 수 없다. ⇒ 1을 원하는 위치로 쉬프트하고 ~(NOT)연산을 해서 0으로 만든다.</p>
<pre><code class="language-c">  0x1&lt;&lt;5    0b0010_0000
~(0x1&lt;&lt;5)   0b1101_1111
// 내가 원하는 비트만 0으로 켜줄 수 있기 때문에 반전</code></pre>
</blockquote>
<ul>
<li>2번 비트를 0으로 클리어하려면 소스데이터에 0b11111011을 &amp;연산</li>
</ul>
<pre><code class="language-c">    a &amp;=~(0x1&lt;&lt;2);
     ~0000_0100
      1111_1011
    &amp; 1111_1111
    ------------
      1111_1011 (0x)</code></pre>
<ul>
<li><p>여러비트 클리어 : 5,3,2번 비트 클리어하려면</p>
<pre><code class="language-c">      a &amp;=~((0x1&lt;&lt;5)+(0x3&lt;&lt;2));</code></pre>
</li>
</ul>
<h1 id="특정-비트-반전토글">특정 비트 반전(토글)</h1>
<ul>
<li>반전 시키고자 하는 비트는 1과 ^(exclusive or)연산 ⇒ 두 피연산자가 같으면 0, 다르면 1로 설정됨</li>
</ul>
<pre><code class="language-c">1^1 = 0
0^1 = 1
--------
~~1^0 = 1
0^0 = 0~~</code></pre>
<ul>
<li>5번 비트를 반전 하려면</li>
</ul>
<pre><code class="language-c">a ^= 0x01&lt;&lt;5;</code></pre>
<ul>
<li>5,3,2를 반전하려면</li>
</ul>
<pre><code class="language-c">a ^= (0x01&lt;&lt;5) + (0x3&lt;&lt;2);</code></pre>
<h1 id="비트-검사">비트 검사</h1>
<ul>
<li><p>특정 비트가 0인지 1인지 검사</p>
</li>
<li><p>5번째 비트가 0/1인지 검사</p>
<pre><code class="language-c">  a &amp; (0x1&lt;&lt;5)

    101010 
  &amp; 100000
  ---------
  &gt; 100000</code></pre>
</li>
</ul>
<h1 id="비트-추출">비트 추출</h1>
<ul>
<li><p>특정 비트만 추출 [6:4]비트만 추출</p>
<pre><code class="language-c">  a &amp; 0x70

  a 0b1[010]1010
  &amp; 0b0[111]0000
  ------------
  &gt; 0b0[010]0000</code></pre>
</li>
</ul>
<h1 id="비트-연산을-편하게">비트 연산을 편하게</h1>
<p>함수로도 가능하지만 ⇒ 작은 부분은 성능을 떨어뜨림 ⇒ 매크로 함수 사용</p>
<pre><code class="language-c">unsigned char a = 0xf0; //1111_0000

a &amp;= ~(0x1&lt;&lt;5); //한 비트 클리어 (5번비트)
a &amp;= ~(0x7&lt;&lt;3); //연속된 여러비트 클리어 (5,4,3번 비트)
a &amp;= ~((0x1&lt;&lt;5)+(0x3&lt;&lt;2)); //떨어져 있는 여러비트 클리어 (5,3,2번 비트)</code></pre>
<p>위 비트 연산을 매크로로 만들면 ⇒ macro.h</p>
<pre><code class="language-c">//한 비트 클리어
#define clear_bit(data,loc)  ((data) &amp;= ~(0x1&lt;&lt;(loc)))

//연속된 여러비트 클리어
#define clear_bits(data,area,loc)  ((data) &amp;= ~((area)&lt;&lt;loc)))

//한 비트 설정
#define set_bit(data,loc)  ((data) |= (0x1&lt;&lt;(loc)))

//연속된 여러비트 설정
#define set_bits(data,area,loc)  ((data) |= ((area)&lt;&lt;loc)))

//비트 검사
#define check_bit(data,loc)   ((data) &amp; (0x1&lt;&lt;loc)))

//비트 추출
#define extract_bits(data,area,loc) (((data)&gt;&gt;(loc) &amp; (area))
</code></pre>
<h1 id="매크로-사용시-치환에-주의">매크로 사용시 치환에 주의</h1>
<pre><code class="language-c">#include &lt;stdio.h&gt;
#define ADD(x) x+x

void main(void){
    int k;
    k=-ADD(5);
}</code></pre>
<p>위의 소스는 두수의 합을 음수화 하려고 한다. ⇒ -10</p>
<pre><code class="language-c">k=-5+5  // k=0이 된다.</code></pre>
<p>다음과 같이 하면 원하는 결과가 나온다.
매크로 할 때 원하는 모든 부분 괄호를 쳐 줘야한다.</p>
<pre><code class="language-c">#define ADD(x) (x+x)</code></pre>
<pre><code class="language-c">int k= -ADD(3)  //-&gt; -6얻고 싶었는데,

int k=-(3+3) //-6</code></pre>
<p>한가지 더!</p>
<pre><code class="language-c">#include &lt;stdio.h&gt;
#define SQUARE(x) (x*x)

void main(void){
    int a = 2;
    printf( &quot;%d&quot;, SQUARE(a+5));

}</code></pre>
<p>다음과 같은 결과가 나온다.</p>
<pre><code class="language-c">(a+5*a+5) = (2+**5*2**+5=17)</code></pre>
<p>원하는 결과는 7*7=49이다. 아래와 같이 수정해야 한다. </p>
<pre><code class="language-c">#define SQUARE(x) ((x)*(x))</code></pre>
<p><strong>(중요) 정리하면 각 인자를 괄호로 묶어주고, 전체 수식 또한 괄호로 묶어주어야 한다.</strong></p>
