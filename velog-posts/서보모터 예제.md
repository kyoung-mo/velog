<h1 id="구성">구성</h1>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/c5c1c175-1b65-48a3-b691-10c28043149e/image.png" /></p>
<ul>
<li>DC모터</li>
<li>감속 기어</li>
<li>제어 회로(PWM)</li>
<li>위치 센서(현재 각도 감지)</li>
</ul>
<h1 id="동작-순서">동작 순서</h1>
<ol>
<li>그림 하단 오른쪽으로 전원 및 위치 신호가 입력되면 보드는 왼쪽 모터를 구동합니다.</li>
<li>모터가 회전하게 되면 기어박스로 회전이 전달되고 최종 샤프트가 회전합니다.</li>
<li>샤프트 하단에 위치한 포텐션미터라는 가변저항으로 현재 위치값을 센싱해서 다시 보드로 전달을 합니다.</li>
<li>현재 회전 위치 값을 전달받은 보드는 입력 위치 비교해서 서보모터 출력을 다시 조정합니다.</li>
<li>현재 위치와 입력 받은 위치가 동일하다면 서보모터구동은 정지합니다.</li>
</ol>
<ul>
<li><p>특징</p>
<ul>
<li>위치 제어 → 각도를 지정할 수 있음</li>
<li>빠른 응답 → 짧은 시간에 바로 움직임</li>
<li>자기 위치 유지 → 지정한 각도에 도달하면 그 위치를 유지</li>
<li>PWM 제어 → PWM 신호(펄스 폭)로 각도 제어</li>
</ul>
</li>
<li><p>연결 방법</p>
</li>
</ul>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/0b9afd43-c2db-4b94-a4fd-01af8103462e/image.png" /></p>
<ul>
<li><p>색 : GND(그라운드) 연결</p>
<ul>
<li>빨강 : VCC(전원), 5V 연결</li>
<li>노랑 : 신호 제어, PWM(3, 5, 6, 9, 10, 11)핀 연결</li>
</ul>
</li>
<li><p><strong>PWM</strong></p>
<ul>
<li>디지털 핀을 이용해 아날로그처럼 동작하게 만드는 기술</li>
<li>0V, 5V만 출력 가능한 디지털 핀, 빠르게 ON/OFF 반복, 원하는 평균 전압처럼 만드는 기술<ul>
<li>사용하는 부품 : LED 밝기 조절, 부저 소리 조절, 서보모터, DC모터</li>
</ul>
</li>
</ul>
</li>
</ul>

<h3 id="예제---라이브러리-미사용">예제 - 라이브러리 미사용</h3>
<pre><code class="language-c">#include &lt;Arduino.h&gt;
#define SERVO 9
int dutyHIGH = 1500;

void setup(){
    pinMode(SERVO,OUTPUT);
}
void loop(){

    for(int i = 0 ; i &lt;= 180; i++){
        dutyHIGH = map(i, 0, 180, 400, 2600);
        // 실제 동작시 데이터 시트와는 다르게 0.4ms ~ 2.6ms까지가 범위인것 처럼 보임

        digitalWrite(SERVO,HIGH);
        delayMicroseconds(dutyHIGH);
        digitalWrite(SERVO,LOW);
        delayMicroseconds(20000 - dutyHIGH); 
        // delayMicroseconds()는 3us ~ 16,383us 에서 매우 정확하게 작동합니다. 그외는 정확성을 보장 할수없다
        // https://docs.arduino.cc/language-reference/en/functions/time/delayMicroseconds/
    }
    for(int i = 180 ; i &gt;= 0; i--){
        dutyHIGH = map(i, 0, 180, 400, 2600);

        digitalWrite(SERVO,HIGH);
        delayMicroseconds(dutyHIGH);
        digitalWrite(SERVO,LOW);
        delayMicroseconds(20000 - dutyHIGH); 
    }
}</code></pre>
