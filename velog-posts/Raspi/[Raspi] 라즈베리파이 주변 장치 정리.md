<li><strong>MicroSD 카드:</strong><ul>
<li><strong>용도:</strong> OS 및 데이터 저장 (HDD/SSD 역할).</li>
<li><strong>권장:</strong> 16GB 이상, Class 10, UHS-I 등급 (속도 중요).</li>
</ul>
</li>
<li><strong>전원 어댑터:</strong><ul>
<li><strong>규격:</strong> USB Type-C.</li>
<li><strong>출력:</strong> 5V 3.0A (15W) 이상 필수.</li>
<li><strong>주의:</strong> 정격 미달 시 'Under-voltage' 경고 및 시스템 불안정 발생.</li>
</ul>
</li>
<li><strong>영상 케이블:</strong><ul>
<li><strong>규격:</strong> Micro-HDMI to HDMI 케이블.</li>
<li><strong>용도:</strong> 모니터/TV 출력.</li>
</ul>
</li>
<li><strong>입력 장치:</strong><ul>
<li>USB 키보드 및 마우스 (초기 설정용).</li>
</ul>
</li>
</ol>
<h3 id="2-선택적-주변-장치-확장-및-편의성">2. 선택적 주변 장치 (확장 및 편의성)</h3>
<ol>
<li><strong>케이스 &amp; 쿨링:</strong><ul>
<li>라즈베리 파이 4 발열 이슈 대비 필수.</li>
<li>방열판(Heatsink) + 쿨링 팬(Cooling Fan) 조합 권장.</li>
</ul>
</li>
<li><strong>네트워크 장비:</strong><ul>
<li>이더넷(LAN) 케이블 (Wi-Fi보다 안정적, 초기 설정 유리).</li>
</ul>
</li>
<li><strong>카메라 모듈:</strong><ul>
<li>Pi Camera (CSI 포트 연결). 영상 처리/스트리밍 프로젝트용.</li>
</ul>
</li>
<li><strong>디스플레이 모듈:</strong><ul>
<li>7인치 터치스크린 (DSI 포트 연결) 또는 GPIO 연결 소형 LCD.</li>
</ul>
</li>
<li><strong>브레드보드 &amp; 점퍼와이어:</strong><ul>
<li>GPIO 핀 테스트 및 회로 구성용 (납땜 불필요).</li>
</ul>
</li>
</ol>
