<h3 id="1-라즈베리-파이-개요">1. 라즈베리 파이 개요</h3>
<ul>
<li><strong>개발:</strong> 영국 라즈베리 파이 재단(Raspberry Pi Foundation).</li>
<li><strong>목적:</strong> 기초 컴퓨터 과학 교육 증진.</li>
<li><strong>특징:</strong> 신용카드 크기, 저전력, 고성능, 저비용($35~).</li>
<li>다양한 라즈베리파이</li>
</ul>
<p><img alt="" src="https://velog.velcdn.com/images/mommers/post/04f01780-6ab0-4a00-a435-e532a7b2cbd3/image.png" /></p>
<h3 id="2-주요-모델-및-사양-raspberry-pi-4-model-b-기준">2. 주요 모델 및 사양 (Raspberry Pi 4 Model B 기준)</h3>
<ul>
<li><strong>SoC (System on Chip):</strong> Broadcom BCM2711.<ul>
<li>Quad-core Cortex-A72 (ARM v8) 64-bit SoC @ 1.5GHz.</li>
<li>기존 3B+ 대비 약 3배 성능 향상.</li>
</ul>
</li>
<li><strong>메모리 (RAM):</strong> LPDDR4-3200 SDRAM (1GB / 2GB / 4GB / 8GB 옵션).</li>
<li><strong>네트워크:</strong><ul>
<li>Gigabit Ethernet (진정한 기가비트 속도 지원).</li>
<li>2.4GHz &amp; 5.0GHz IEEE 802.11ac 무선 LAN.</li>
<li>Bluetooth 5.0, BLE(Bluetooth Low Energy).</li>
</ul>
</li>
<li><strong>USB 포트:</strong><ul>
<li>USB 3.0 x 2 (파란색, 고속 데이터 전송).</li>
<li>USB 2.0 x 2 (검은색, 주변장치 연결).</li>
</ul>
</li>
<li><strong>영상 출력:</strong> Micro-HDMI x 2 (4K 60Hz 듀얼 디스플레이 지원).</li>
<li><strong>전원 입력:</strong> USB Type-C (5V 3A 권장).</li>
</ul>
<h3 id="3-gpio-general-purpose-inputoutput">3. GPIO (General Purpose Input/Output)</h3>
<ul>
<li><strong>핀 구성:</strong> 40핀 헤더 (Model B+ 이후 표준).</li>
<li><strong>전압:</strong> 3.3V 로직 레벨 (5V 입력 시 보드 손상 주의).</li>
<li><strong>주요 핀 기능:</strong><ul>
<li><strong>Power:</strong> 3.3V, 5V.</li>
<li><strong>Ground:</strong> 0V (GND).</li>
<li><strong>GPIO:</strong> 일반 입출력 제어.</li>
<li><strong>I2C (SDA/SCL):</strong> 근거리 통신.</li>
<li><strong>SPI (MOSI/MISO/SCLK/CE):</strong> 고속 직렬 통신.</li>
<li><strong>UART (TX/RX):</strong> 시리얼 통신.</li>
</ul>
</li>
</ul>
